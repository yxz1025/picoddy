# 桌面扩展能力：后续迁移规格与验收门槛

状态：规划项，尚未实现。不能因为基础工作台可用而把本文件标为完成。
实施顺序：先验收 P1–P5 的真实执行闭环，再按以下切片迁移；每个切片有独立接口、租户授权和回归证据。

## A. 企业身份与 SkillHub

桌面企业登录持有的本地 token、系统钥匙串和 loopback 回调不直接搬到云端。

1. 企业管理员提供已注册的 Web 应用 clientId、clientSecret、issuer/认证服务、回调域名及测试账号；服务端保存 secret，浏览器只拿本站 session。
2. 对接现有企业协议时采用服务器回调、state/nonce（协议支持时 PKCE）；身份映射使用稳定 subject，不用可变显示名作为 owner_id。
3. 将账号关联、禁用、退出及企业 token 续期分开实现。禁止只验证前端声明的企业用户 ID。
4. SkillHub 搜索/详情/下载使用服务端固定上游地址；安装结果仍经过现有 parseSkillPackage 校验，不能绕开版本冻结。
5. 用户个人技能和企业共享技能区分归属。共享技能升级不覆盖已运行任务快照；企业凭据不放入普通技能包。

验收：state 重放、账号关联冲突、禁用后 session 失效、企业目录权限、恶意下载包、升级并发、真实企业登录/退出。
外部阻塞：企业 Web 应用注册、真实测试账户及可到达的服务环境。

## B. TAPD/零售等业务工作台

通用 MCP 已有配置入口，但不是业务 UI 的替代验收。

1. 按桌面领域逐项列出现有业务读写、字段约束和鉴权来源。
2. 业务 UI 放 `cloud/web/src/features/`，领域接口放 `cloud/src/domains/`；不得 import 桌面模块或暴露桌面 IPC。
3. 用户身份与第三方凭据绑定，固定目标服务/组织/空间；所有请求校验本站 owner 与第三方权限。
4. 需求、缺陷、流水线等写操作显式确认、记录审计关联 ID；真实联调默认只读，生产写入另获授权。
5. 远程 MCP、CLI 和企业 Web API 的认证生命周期分别实现，不用任意用户提供 URL 的凭据代理。

验收：双用户跨组织访问拒绝、分页/字段回显、真实只读查询、授权后的测试环境写入、错误恢复。

## C. RAG 与长会话

当前提供文档文本分页，不等于完整 RAG；上下文超限会报错。

1. 文档解析在沙箱进行；解析后带文件 hash、页码/表格位置的文本块进入用户私有知识库。
2. 明确 embedding provider、版本、向量维度、数据外发授权和成本；再决定 PostgreSQL pgvector schema，不能任意选择 embedding 供应商并发送企业文档。
3. 检索过滤 owner_id、project_id 和授权文件集合先于结果返回；结果保留来源/版本/页码。
4. 删除/更新文件触发索引失效；幂等索引任务和失败重试独立于对话 run。
5. 长会话压缩保存原始完整消息和压缩点；不得打断工具调用/结果配对，不把压缩摘要当作授权。

验收：引用正确、跨租户无法检索、旧版本失效、中文召回、索引中断重试、成本与容量指标。

## D. 消息分支与技能草稿

1. 分支复制所选截点的完整消息链，禁止在未完成工具调用之间分叉；新分支有自己的 conversation/run 身份。
2. 技能编辑工作区放沙箱。草稿属于用户，有 baseVersion、draftVersion 和文件集，不直接覆盖当前发布版本。
3. 修改后展示 diff；发布必须重新经过路径/大小校验，并以 expectedVersion 原子切换 currentVersion。
4. 正在执行的任务仍引用已冻结文件集。回滚创建新的当前版本指向，不改历史版本内容。

验收：同时编辑产生409、发布失败不留半包、沙箱脚本不能越权发布、旧任务内容不变、分支上下文一致。

## E. 完整 Pi 插件宿主

当前 Worker 只注册平台可信工具，不把用户插件加载进控制平面。

1. 用户 JS 扩展在沙箱内独立插件进程运行，通过限定 RPC 输出工具定义与事件。
2. Worker 验证名称冲突、schema 大小、返回值大小、生命周期与 run 所属；不能由插件注册任意宿主命令或更改审批。
3. 插件所需文件/网络/凭据属于明确的运行时能力；依赖桌面 UI、OS 或 Electron 的扩展需声明不支持或迁移成 Web 扩展。
4. 单独处理插件 crash、超时、取消和清理；插件审计同普通工具，不给隐藏权限。

验收：恶意插件无法读取 Worker env/DB、无法注册高权限工具、终止后无遗留进程、桌面代表性插件在兼容范围运行。

## F. 安全预览与交互浏览器

当前交付物是鉴权下载；browser 工具提供一次导航文本/截图，交互操作可由 Playwright 脚本在任务内执行。

1. PDF/Office 转换产物在沙箱生成，读取和下载继续按 owner 鉴权；预览 URL 短期授权且不可枚举。
2. HTML/脚本工件必须使用隔离预览域或无 allow-same-origin 的受限 iframe，不能与登录工作台同源执行。
3. 交互浏览器会话/远程画面绑定 owner/run；输入事件、截图和下载走鉴权通道，不暴露 Chromium 调试端口。
4. 浏览器认证 cookie 不混用不同用户，任务结束即回收；若需持久 profile，独立加密持久卷和版本/租约设计后再实现。

验收：HTML 无法取本站 cookie、预览越权拒绝、截图/输入与 run 匹配、任务结束连接断开、用户浏览器权限不被云端绕过。
外部阻塞：独立预览域、HTTPS 与目标环境网络配置。

# 云端连接器管理设计

## 背景与目标

用户已批准采用云端通用方案：浏览器提供与桌面一致的配置、连接、工具发现及授权体验，服务端按用户存储配置和加密凭据，MCP 与 OAuth 网络执行留在 OpenSandbox。只改 cloud，不改变桌面端。

## 现状

resources 已保存用户级 connector 配置与 AES-GCM 加密的 env/headers；Agent 在任务沙箱通过 MCP SDK 调用，但浏览器适配器拦截连接和 OAuth，connected 始终为空。配置更新会丢弃扩展秘密字段。现有数据库禁止自动迁移，因此复用 resources.data/secret，不新增表、不重建业务数据库。

## 非目标

不共享桌面数据，不在浏览器运行 stdio，不在 API 主机运行用户命令，不替用户同意第三方权限；不保证不支持标准 MCP OAuth 的企业专有协议可自动接入。

## 方案

1. 连接器以 UUID 为服务端身份；桌面 name 接口解析时遇到重名拒绝，避免串用凭据。公开配置支持 enabled/displayName/exposure/toolExposure。秘密 env/headers/OAuth 凭据仅在 secret 中保存，禁止返回浏览器。
2. POST /api/mcp/connect 在限时临时沙箱建立 MCP 会话、列出工具，然后销毁沙箱。connected 表示最近探测成功，不表示 API 上常驻 MCP 进程；状态、工具名和探测时间持久化。断开清除探测状态。编辑配置清除旧连接状态。操作使用版本/代次校验避免迟到结果覆盖编辑、删除或退出授权。
3. OAuth 使用现有 MCP SDK 处理 discovery、注册、PKCE、交换和刷新；网络请求在临时沙箱执行。服务端加密保存 client、tokens、verifier、discovery 和短期 challenge；state 绑定 owner、connector、当前 session，并一次性消费。浏览器只得到授权 URL 与安全状态。第三方预注册客户端通过连接器配置录入，client secret 不在响应中暴露。
4. callback 为固定 PUBLIC_ORIGIN 路径，不接受自定义返回地址。取消与退出使旧 challenge 失效；退出删除本地 token。提供方支持撤销时尝试撤销，远端不可用不阻止清除本地凭据。刷新不得把 token 交给不同 issuer。
5. Agent 调用使用用户连接器授权凭据；授权缺失或过期提示重新授权，不降级为跨用户共享凭据。配置变化与撤销需在调用前校验，不使用已撤销快照 token。
6. 沙箱操作有超时、输出大小限制和 finally 清理，创建失败按操作 metadata 清理；失败信息脱敏。控制面不直接 fetch 用户指定 URL。生产网络访问由沙箱出口规则管控，授权 URL 限 HTTP(S)、无嵌入凭据，生产只允许 HTTPS。

## 分阶段实施与验证

- P1：配置保留、连接/断开/工具列表、安全 DTO 与用户隔离回归。
- P2：OAuth 开始、回调、取消、退出、PKCE/state 一次性与刷新回归。
- P3：前端适配与 Agent 授权使用，保持桌面卡片布局与交互。
- P4：完整自动化、构建及真实 OpenSandbox MCP 联调；OAuth 使用受控测试服务验证，真实提供方需其注册配置及用户亲自授权。

## 风险与影响

OAuth 提供方可能不支持动态注册，届时需要其 client ID。临时沙箱探测有冷启动延迟；它与实际任务执行隔离。数据库不做迁移，现有业务数据不删除。修改仅涉及 cloud 域服务、HTTP 路由、沙箱 runner、Agent MCP 工具、前端适配和测试。Node/React 控制面不引入平台专用进程，执行镜像仍为 Linux OpenSandbox。

## 实施记录

### 2026-10-14 授权窗口交互修正（既有已确认浏览器授权范围）

当前按钮仅返回链接，回调只输出静态成功页，导致用户必须再次点击且不能返回原页面。修正为点击事件内同步打开空白授权窗口，清除 opener 后再等待预设/授权请求并导航；知识库预设异步步骤共用该窗口引用，避免 useEffect/await 后打开被弹窗策略拦截。失败/取消关闭临时窗口；被浏览器拦截时保留安全手动链接。授权成功回调仅执行 nonce CSP 允许的固定关闭脚本，不能关闭时回到同源根路径，不接受外部 returnUrl、不反射 OAuth code/state。原页面以服务端状态轮询为授权依据，完成后关闭窗口、聚焦原页面并刷新连接；刷新页面恢复 authorized 状态也触发连接检查，不刷新原会话。范围仅 cloud 标准 OAuth UI/回调；真实账号同意仍由用户完成。验证：同步窗口与异步跳转回归、成功回调 nonce/固定返回及失败页不反射查询、模拟浏览器自动打开/关闭/授权状态更新和弹窗拦截分支、类型与 Web 构建。沿用既有设计授权的测试/构建范围。

设计已获本轮用户“按照云端通用的方案来设计和实现”授权，实施与验证进行中。

2026-10-14 补齐主路由注册与原子配置保存，删除旧前端适配中的不支持分支。配置保留缺省凭据，支持启停、显示名、描述、工具暴露配置、HTTP/SSE/stdio；浏览器提供测试连接、断开、工具列表及 OAuth 开始、取消、退出。首次主动授权启用标准 OAuth 并更新配置代次，退出清除探测状态。任务调用重新读取当前用户授权凭据、核对配置代次并按需刷新令牌，不使用过时凭据快照。探测 SQL 保留 PostgreSQL 原始时间精度，避免微秒被 JS Date 截断导致误报配置变更。

# 云端 API Key 模型设置补齐

状态：本批次 API Key 配置、目录、连接测试及资源身份适配已实现并验证；真实供应商调用待用户输入 Key 后验证，订阅模式未实现。

补充约束：以桌面端样式及操作习惯为基准，不另行设计云端模型管理界面；仅为云端用户隔离和已有资源 API 做必要适配。首次保存模型与 Key 原子创建，不引入空模型占位记录。

## 目标与范围

仅修改 cloud/。沿用桌面设置样式及模型选择交互，支持首次输入 Key、读取模型目录、保存选定模型、最小真实推理测试、刷新页面后继续使用。保留用户已有模型记录及默认选择。不同用户的 Key 使用现有加密 resource secret 隔离；不共享桌面凭据，不实现 ChatGPT 订阅/OAuth，不访问用户本机 Ollama。

## 现状

云端适配器对目录、连接测试及订阅统一返回 501；后端只有模型 CRUD 和 API Key 推理。桌面渠道保存分 Key/模型两步，云端要求模型与 Key 同时创建，导致首次预设渠道配置无法闭环。

## 方案

- 在云端设置领域新增诊断服务，原生 HTTP 路由只负责认证和 DTO。支持 POST `/api/providers/:provider/models` 与 `/api/settings/test-connection`，返回桌面可消费的数据格式。
- 可使用当前输入但未保存的 Key；仅用于本次请求，不持久化。没有输入时按 owner、provider、模型/资源 ID 和端点定位已保存凭据；多个不明确候选拒绝，不选其它用户或其它端点的 Key。
- 目录按现有六个云端 provider 的协议规范化模型 ID/名称，用户仍可手动输入。自定义 OpenAI 兼容端点只允许管理员许可的 HTTPS 域名。
- 连接测试使用所选模型发最小推理，明确可能消耗供应商额度；只有收到有效推理响应才返回成功。401/403、限流、超时、格式错误等返回固定安全错误，不回显上游响应/Key。
- 所有新出站请求限制时间、响应体大小及并发，不跟随重定向；HTTPS、域名白名单、实际连接 DNS 地址检查共同阻断私网/元数据访问。保存的 Key 不允许因临时 endpoint 覆盖而发到另一个地址。
- 前端移除订阅控件及自动订阅状态读取，将目录/测试请求接到真实云端路由；预设渠道保存所选模型和 Key，已有模型只在明确操作时更新。不调整其它工作流或数据库 schema。
- 设置、聊天模型选择和会话恢复使用持久化模型资源 UUID 保持凭据身份，界面仍显示桌面式渠道/模型名称。自定义配置不按相同地址合并；编辑更新选中资源、留空 Key 保留原值，改端点需重输 Key，删除只删除选中资源。首次配置后仅为空的聊天模型选择填入默认值，不覆盖用户已选模型。

## 验证

测试先验证现有 501/首次保存失败，再覆盖各协议目录及推理请求、用户隔离、密钥不回传、不跨端点发送、SSRF/重定向/超时/超大响应、默认模型不变及 API Key-only UI。运行定向与全量云端回归（专用测试库）、类型检查和构建；浏览器模拟只验交互，真实供应商调用需用户自行输入 Key 并点击测试，不把模拟成功称为真实模型验收。

## 部署与验证边界

- 目录、连接测试仅使用当前用户的云端凭据或本次输入，不读取桌面端数据。
- 自定义端点须加入管理员配置的 `MODEL_ALLOWED_HOSTS`；该探测接口只接受公网 HTTPS 443。
- 单 API 进程限制每用户 2 个、全部用户合计 32 个并发探测；多副本部署仍需网关/分布式限流。
- 目录当前仅取供应商第一页，未列出的模型仍可手动输入 ID；目录出现不代表账号有调用权限。
- 出站超时和响应大小有代码限制；测试覆盖地址政策、协议和模拟错误，并未以真实供应商验证所有网络故障路径。
- 浏览器回归使用模拟接口验证输入 Key、读取目录、首次保存模型、读取保存后的资源并测试连接；不访问真实 Key、业务数据库或供应商。

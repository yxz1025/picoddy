# 桌面界面对齐实施记录

## 源码与运行入口

`web/index.html` 已切换至 `web/desktop/src/main.tsx`。该目录独立复制桌面 React 组件、CSS、主题变量与状态模型；`web/public/` 保存对应静态资源，`web/desktop/shared/` 保存必要的共享展示契约。运行时不导入根目录桌面源码。

两套实现分别维护。升级桌面 UI 时应逐个比较组件，不可重新整目录覆盖云端 API、认证、流式处理及浏览器适配。

## 本次改动

- 保留桌面侧栏、欢迎页、聊天布局、输入框、设置弹窗、专家/技能/连接器、项目及自动化页面的组件结构与 CSS。
- 登录沿用桌面视觉，使用云端账号密码；企业 CAS 尚未接入。
- 原生悬浮窗和自动更新不启用；系统权限页改为云端执行环境说明。
- 云端工作空间不接受客户端本机路径。上传文件后通过用户鉴权接口读写。
- 技能页增加个人技能包导入，支持 SKILL.md / ZIP；运行仍按后端冻结版本。
- 普通对话中的技能标签也显式转换为 selectedSkillNames，云端不依赖桌面的隐式斜杠解析；MCP 只在任务沙箱中建立连接。
- 专家是每次运行的显式选择，不伪装成桌面持久会话绑定；刷新页面后需重新选择。
- 文件侧栏保留桌面外壳，图片和文本通过云端鉴权下载接口预览。HTML/SVG 仅作为文本展示，不执行；Office/PDF 在线预览暂未接入，提供下载。
- 自动化适配五段式 Cron；仅能精确转换的分钟间隔允许转换。单次任务、有效期、业务推送、手动触发和历史面板尚未接入。
- 原生文件定位转换为发布文件下载；云端未实现的操作必须明确报错，禁止模拟成功。
- 当前执行模式为 Craft；Ask/Plan/只读模式的工具约束尚未接入，选择这些模式会明确拒绝运行，不以普通执行冒充只问答或仅规划。
- 模型页增加与原样式一致的云端模型创建/删除卡片；密钥和模型 ID 一次提交，不将仅缓存在浏览器中的密钥标为已保存。
- 默认本地持久文件存储，S3 可选；本地数据目录不进入 Git 与 Docker 构建上下文。

## 尚未达到的验收条件

**复制桌面 UI 不等于全量功能完成，也不等于视觉一致性已验收。** 企业 SSO、SkillHub、TAPD、受管 CLI、完整插件、草稿与分支、实时浏览器、完整 Office 预览仍按 `05-desktop-parity.md` 实施。

尚未执行截图比对、浏览器操作测试、Web 构建、数据库集成或真实 OpenSandbox 任务。测试/构建需要用户明确授权，真实运行还需要 PostgreSQL、OpenSandbox 与模型配置。仅前端 HTTP 200 不能证明登录或 Agent 执行可用。

## 验收清单（待授权执行）

1. 两个用户分别登录，核对会话、文件、技能、模型与退出后的隔离。
2. 相同窗口尺寸下比对桌面/浏览器的侧栏、欢迎页、聊天、设置与弹窗；检查浅色/深色主题。
3. 上传附件、安装含脚本技能包、启停技能并发起任务；核对实际冻结版本与沙箱内文件。
4. 验证流式文本、工具状态、审批拒绝/重试、取消、刷新恢复及会话切换。
5. 检查模型密钥保存、默认模型选择、MCP 凭据更新不能清空未回传的秘密。
6. 检查本地存储重启持久性、API/Worker 共享卷、路径穿越拒绝、S3 模式配置校验。

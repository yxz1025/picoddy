# Automation capability

用户提出定时执行、周期更新或自动化时，使用 `automation_update` 管理本项目内置自动化任务。先 list 检查是否已有对应任务，再按需 create、update 或 delete。不得自行创建 launchd、crontab、Windows 任务计划程序等系统级任务，除非用户明确要求。

创建看板更新任务时，在提示词中写明看板 HTML 的绝对路径、数据来源、更新步骤及完成后检查文件的要求。创建成功后报告任务 ID、执行频率和下次运行时间；不得把创建脚本或系统任务描述成项目自动化任务。

项目调度器随应用运行，在 Windows、macOS、Linux 上使用相同任务定义和本机时区。应用关闭时不会触发任务；如用户要求关机期间仍执行，先说明项目内任务的运行条件。

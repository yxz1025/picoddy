# 路由布局与代表页面模式

以下为候选模式，审核状态见 [overview.md](overview.md)。只继承指定结构；样本的业务规则、局部 CSS、历史问题不整体继承。

## 路由与外壳（F → C）

原型外壳应根据展示方式选择：

```text
独立演示：应用导航 → 内容区 → 列表 / 表单 / 详情
嵌入宿主：宿主导航 → 内容区 → 列表 / 表单 / 详情（不重复导航）
详情内部：返回入口 → 标题与操作 → 标签导航 → 当前实体内容
```

- 原后台有独立与微前端两种外壳。原型按本次展示方式选一套，不能重复侧栏和左侧留白。
- 列表、新建、详情必须有明确去向，可以用页面路径、hash 或本地视图状态实现，不要求还原生产路由字符串。
- 导航中隐藏不等于无权访问；无权限页也应有明确状态。
- 返回列表保留筛选和页码需要原型实际实现，不能把缓存配置当成已保证的行为。
- 不继承测试菜单、固定宿主高度偏移和无关业务导航。

## P-01：筛选列表

提取样本：自动续订授权记录列表；以下描述已包含生成原型所需结构。

```text
内容卡片
  筛选区：关键词 / 状态 / 其他必要条件 ─ 查询、重置
  操作区：新增或导出、批量操作（按业务需要）
  列表区：表头 / 数据行 / 行操作 / 空、加载、错误状态
  分页区：总数 / 页码 / 每页条数
```

取用：行内筛选表单 + 响应式栅格 + C-01 列表；查询回第一页，重置恢复 PRD 定义的初值。样本只有行操作，不应为所有列表凭空增加新增、导出或批量按钮。数字 0 是合法筛选值，不用 truthy 过滤把“拒绝=0”丢弃。

样本的列全部居中是页面事实，不升为统一对齐规范。候选：描述文本左对齐、数量 / 金额右对齐、短状态和操作按页面统一。长列表按稳定 ID 选中，分页选择清空 / 保留须在 PRD 明确，C-01 现状为清空。

原型最小验证：筛选确实改变行集，查询回第一页，重置有效，页码与总数对应，点击行操作完成状态更新，模拟失败显示重试而非“暂无数据”。

## P-02：短表单弹窗

提取样本：字典编辑弹窗。

取用：标题、新建空值 / 编辑回填、字段旁校验、底部取消 / 确认、提交中状态。样本 width=600，label 栅格 sm=5、输入 sm=16；可作为短表单候选起点，不是所有弹窗固定尺寸。窄视口应适配可用宽度。

候选提交顺序：字段预处理 → 校验 → 锁定提交 → 模拟请求 → 成功反馈、更新列表并关闭；失败保留输入、展示错误并允许重试。取消不保存；有未保存编辑时按 PRD 约定提示。底部推荐统一“取消 / 保存”，样本“关闭”是否保留由负责人决定。

例外：X-05 的失败关闭行为 不复制；原实现先校验后 trim 也不能当成“空白字符必填校验已完善”。属性键在规则里必填，显式 required 标记不一致，原型需以业务规则统一展示。

## P-03：复杂分组表单

提取样本：搭配师分组详情表单。

结构：C-02 返回标题 → 页面加载 → 基本信息 / 业务设置等语义分组 → 图片上传 / 标签 / 选择输入 → 保存操作。可用锚点帮助长表单定位；沿用分组思路，不继承样本中随业务状态改变的固定锚点位置。

历史表单存在不同技术实现，原型应选一致的表单模型，只保持字段、布局和交互契约。无需为了参考长表单装配原生产框架。

照片大小、标签数、手机号规则、字段上限、保存权限根据本次 PRD 指定，不能将搭配师业务限制施加给所有业务。生成原型需实现编辑回显、校验、上传模拟及保存结果。

## P-04：多标签详情

提取样本：会员多标签详情。原型只需明确实体 ID 与标签视图，无需知道生产路由。

结构：返回列表 → 详情卡片 / 状态与业务操作 → 横向标签导航 → 当前标签内容。样本标签由路由配置派生，展示当前标签对应内容。子页链接必须携带相同实体 ID；切换标签不应显示另一条记录的缓存内容。

取用：C-02、明确返回目的地、嵌套详情模块。候选需显示“无权限 / 不存在 / 加载失败”独立状态，空字段可用 `—`，不能把 0 渲染为空。

权限与业务限制分离：样本“下盒”受操作权限控制，另由黑名单状态控制禁用。不要把黑名单等业务状态当成登录角色权限。嵌入模式隐藏返回头属于嵌入特例，不是所有详情页默认行为。

## 模式选择与输出

| 需求 | 首选 | 需要补充的产品信息 |
| --- | --- | --- |
| 查询一组记录 | P-01 | 筛选初值、列、状态、分页、允许的行操作 |
| 编辑少量相关字段 | P-02 | 必填、校验、保存与取消结果 |
| 多分组、上传、联动 | P-03 | 字段分组、联动清空、未保存离开规则 |
| 读一个实体的多类信息 | P-04 | ID、标签、只读 / 可操作内容与返回目标 |

每个 PRD 页面给出“模式 ID → 组件 ID → 字段值契约 → 交互规则 ID → 新增差异”。交互参考见 [reference.html](reference.html)。选择 P-01 不自动意味着业务组件全可用；未收录组件声明为新增候选。

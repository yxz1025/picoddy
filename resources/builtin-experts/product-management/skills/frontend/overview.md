## 这份规范如何使用

这是一份可整体携带的技能包。**产品专家无需访问原仓库，也不依赖源码链接。** 需要的布局、变量、组件值模型、交互规则和示例都包含在本目录。

- [design-tokens.md](design-tokens.md)：视觉变量、尺寸和可复制 CSS。
- [components.md](components.md)：按产品能力查组件，包含单多选、输入、输出和边界。
- [page-patterns.md](page-patterns.md)：列表、短表单、分组表单、多标签详情。
- [interactions.md](interactions.md)：校验、权限、加载、错误、反馈和验收。
- [reference.html](reference.html)：直接用浏览器打开的交互参考页，不依赖网络或构建工具。
- [SKILL.md](SKILL.md)：给产品专家的技能入口。

交互样例是按候选规范重新实现的原型，用于评审视觉与行为，不声称是生产页面截图或生产组件的精确复刻。

## 事实、规范候选与历史例外

| 标签 | 意义 | 使用规则 |
| --- | --- | --- |
| F：已核实事实 | 静态检查确认的现有行为，例如搭配师单选保存一个 ID | 用于理解能力，不能自动当作规范 |
| C：候选规范 | 从现有实践中选定的规则，或为原型补全的行为 | 经负责人确认后作为正式生成基线 |
| X：历史例外 | 不一致、业务特例、旧实现缺陷 | 不随页面样本继承 |

当前所有 C 均待审核，可以用于明确标注的评审预览。正式 PRD 应使用已批准版本，不能因文件已生成就自称“已按正式规范验收”。

## 风格范围

参考体系是 Vue 2、Ant Design Vue 1.x 的桌面业务后台：紧凑筛选、白色卡片、蓝色主操作、数据表格、标签详情与表单弹窗。产品专家可用 HTML、React 或 Vue 实现，保留视觉与值模型即可，不要求装配原生产技术栈。不要生成营销大屏、渐变落地页或移动小程序布局。

取样覆盖：自动续订记录列表、字典编辑弹窗、搭配师分组表单、会员多标签详情、要盒需求中的搭配师选择。只取其中指定结构，不把整个历史页面定为模板。

## 不应继承的历史行为

| ID | 已发现的问题 | 规范处理 |
| --- | --- | --- |
| X-01 | 外壳夹有权益中心测试菜单 | 按本次 PRD 定义导航，不复制测试菜单 |
| X-02 | 微前端高度类名不一致，存在宿主固定偏移 | 只保留一套外壳，按容器适配，不继承固定偏移 |
| X-03 | 构建主色 #1375F2、设置默认色 #1890FF 和预编译样式并存 | #1375F2 仅为候选，负责人核验真实主题后确定 |
| X-04 | 页面中存在多种蓝色、操作间距、字体等局部写法 | 使用本规范选定变量，不按历史出现频率投票 |
| X-05 | 部分表单失败也关闭，先校验后去空格 | 失败保留输入，文本预处理后再校验 |
| X-06 | 部分列表失败后未完整结束 loading | 原型补独立错误状态和重试，不伪装成零条 |
| X-07 | 现有权限指令只处理部分条件和初次插入 | 原型以明确角色矩阵模拟，不声称是完整权限系统 |
| X-08 | 上传存在多个变体及依赖真实服务的默认配置 | 规范规定用户行为，原型本地模拟，不复制服务配置 |

本次交付不修改生产业务实现。源码事实已转写为可独立消费的描述；维护者更新时可重新检查代码，但产品专家生成 PRD 不以仓库可用为前提。

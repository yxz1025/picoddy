# 分群动作剧本

> 每个剧本包含：**目标 / 人群定义 / 触达节奏 / 权益配置 / 话术要点 / 预期指标 / 常见坑**。
> 话术为参考模板，**必须按品牌调性改写**，不要直接照抄。

---

## 剧本 1｜潜客首购（注册未购）

| 项 | 内容 |
|---|---|
| **目标** | 7 日内完成首购 |
| **人群** | 注册 >24h 且无有效订单 |
| **触达节奏** | T+1 新人礼提醒 → T+3 爆品推荐 → T+6 券到期提醒（**到期提醒是转化最高的一触**） |
| **权益** | 无门槛小额券（短效 7 天）或首单立减；**券的有效期越短，转化越快** |
| **话术要点** | 强调"仅剩 X 天"+ 具体商品 + 具体能省多少钱。不要说"欢迎加入" |
| **预期指标** | 7 日首购率（起步 5–12%） |
| **坑** | 新人礼太大 → 吸引羊毛党；只发券不推商品 → 用户不知道买什么。**券 + 具体商品**才有转化 |

**话术模板**
> 你的 20 元新人券还有 2 天到期 ⏰
> 用它买【XX 商品】只要 39 元（原价 59），今天下单明天就能到。
> 👉 立即使用

## 剧本 2｜新客二购（**ROI 最高的一条，优先做**）

| 项 | 内容 |
|---|---|
| **目标** | 30 日内完成第二次购买 |
| **人群** | 仅 1 笔有效订单，且距首购 ≤30 天 |
| **触达节奏** | T+3 使用引导/关怀 → T+7 关联推荐 → T+14 短效复购券 → T+25 券到期提醒 |
| **权益** | 品类关联券（不是全场券）、复购立减、二单双倍积分 |
| **话术要点** | 先给价值（怎么用好已买的东西），再给推荐。**第一触不要卖货** |
| **预期指标** | 30 日二购率（起步 15–25%，优秀 >35%） |
| **坑** | 上来就发券 → 训练用户等券；推荐同款重复品 → 转化极低。要推**互补品**不是同类品 |

**话术模板（T+3 关怀，不卖货）**
> 你买的【XX】收到了吗？
> 分享 3 个用法，很多人第一次都用错了 👉【内容链接】
> 有问题随时找我们，会员专属客服 1 分钟响应。

**话术模板（T+14 复购券）**
> 上次买的【XX】差不多该补了？
> 给你留了一张 15 元券（7 天有效），配【YY】一起用效果更好。

## 剧本 3｜重要价值客户维护（R高 F高 M高）

| 项 | 内容 |
|---|---|
| **目标** | 维持忠诚 + 转化为推荐者，**不是刺激复购** |
| **人群** | RFM 分群 #1 |
| **触达节奏** | 月度 1 次（低频高质量），新品优先通知、专属活动邀请 |
| **权益** | **不给折扣**。给：新品优先购、专属客服、免费服务、活动邀请、共创权、生日惊喜 |
| **话术要点** | 用"专属/优先/邀请"的语气，不用"优惠/折扣/限时" |
| **预期指标** | 留存率、NPS、推荐带来的新客数 |
| **坑** | **给这群人发大额券是纯粹的成本浪费**——他们本来就会买。这是会员运营最常见的钱花错地方 |

**话术模板**
> 【新品】下周三上市，给你留了优先购资格（比公开发售早 48 小时）。
> 数量有限，需要我帮你留一件吗？

## 剧本 4｜重要保持客户抢救（R低 F高 M高）★最高优先级

| 项 | 内容 |
|---|---|
| **目标** | 查明沉默原因并挽回。**这是最值得投入的一群人** |
| **人群** | RFM 分群 #2：曾经高频高额，最近沉默 |
| **触达节奏** | 发现即触达，不等批量。企微/电话 1v1 |
| **权益** | 可给高价值权益，但**先问原因再给权益** |
| **话术要点** | 先关心，不推销。"最近没看到你，是不是我们哪里没做好？" |
| **预期指标** | 回访率、回购率、流失原因回收率 |
| **坑** | 直接发大额券 → 显得廉价，且掩盖了真实问题（服务事故？竞品挖角？需求消失？） |

**话术模板（企微 1v1）**
> 张女士您好，我是您的专属顾问小 X。
> 注意到您有段时间没来了，之前是不是有哪次体验没做好？
> 方便的话告诉我一句，我来处理。也给您留了一份小礼（无需消费即可领）。

> **核心：这一群人的流失原因，是整个会员体系最有价值的信息来源。**回收到的原因应直接进产品/服务迭代清单。

## 剧本 5｜一般价值客户提客单（R高 F高 M低）

| 项 | 内容 |
|---|---|
| **目标** | 提升客单价 |
| **人群** | 常来但每次花得少 |
| **触达节奏** | 结合购买周期，在其"该买了"的时点推 |
| **权益** | 阶梯满减（门槛设在其 ATV 的 1.3–1.5 倍）、套装组合价、加价购、积分+现金换购 |
| **话术要点** | "再加 XX 元可省 XX"——把门槛差额说得很具体 |
| **预期指标** | ATV 提升幅度、连带率 |
| **坑** | 满减门槛设太高 → 用户直接放弃。**门槛要"跳一跳够得着"** |

## 剧本 6｜升级冲刺（距升级门槛 <20%）

| 项 | 内容 |
|---|---|
| **目标** | 推动升级 |
| **人群** | 累计消费达到下一等级门槛的 80% 以上 |
| **触达节奏** | 触发式，达到 80% 立即触达；周期末前 15 天再触达一次 |
| **权益** | 限时双倍成长值、升级礼包预告 |
| **话术要点** | **必须写清"还差多少"和"升级后能得到什么具体的东西"** |
| **预期指标** | 升级率、冲刺期 GMV |
| **坑** | 只说"快升级了"不说差多少、不说升级有啥用 → 无效 |

**话术模板**
> 你距离【金卡】只差 320 元 ✨
> 升级后立即解锁：全年免运费 + 生日双倍积分 + 专属客服
> 本月还剩 9 天，本周下单还享双倍成长值。

## 剧本 7｜保级挽留（**损失厌恶，效果通常优于升级引导**）

| 项 | 内容 |
|---|---|
| **目标** | 防止掉级 |
| **人群** | 当前等级用户，距周期末 <45 天且未达保级线 |
| **触达节奏** | T-45 / T-15 / T-3 三次 |
| **权益** | 保级冲刺任务、限时双倍成长值 |
| **话术要点** | **强调"将失去什么"，而不是"能得到什么"** |
| **预期指标** | 保级率、周期末 GMV |
| **坑** | 语气过于威胁会引发反感。用"提醒"的口吻，并给出明确解法 |

**话术模板**
> 提醒：你的【金卡】权益将在 12 月 31 日到期。
> 还差 480 元即可保级，继续享受免运费 + 专属客服 + 生日礼。
> 本月消费享双倍成长值，一单即可达成。

## 剧本 8｜预沉睡打断（R 超个人基线 1.5×）

| 项 | 内容 |
|---|---|
| **目标** | 在真正沉睡前拉回 |
| **人群** | R > 个人历史平均间隔 × 1.5 |
| **触达节奏** | 触发式，单次轻触达；无响应则 7 天后再一次，仍无响应转沉睡池 |
| **权益** | **先零成本**：积分到期提醒、新品通知、内容推送。第二次才给小额权益 |
| **话术要点** | 不要说"好久不见"（暗示疏远），说"你关注的 XX 有更新" |
| **预期指标** | 预沉睡回流率（目标 >15%） |
| **坑** | 一上来就发大额券 = 教会用户"不买就有券"，会主动养成"装沉睡"的行为 |

## 剧本 9｜沉睡召回（阶梯投入）

| 阶段 | 时点 | 动作 | 成本 |
|---|---|---|---|
| 一探 | T+0 | 积分/权益到期提醒（**你有 XXX 积分即将过期**） | 0 |
| 二探 | T+7 | 新品 / 内容 / 场景提醒 | 0 |
| 三探 | T+21 | 免运费 / 小额券 | 低 |
| 四探 | T+45 | 中额权益（**仅对预测 CLV 高的人群**） | 中 |
| 五探 | T+60 | 高价值人群转人工 1v1，同时回收流失原因 | 高 |
| 收尾 | T+90 | 仍无响应 → 降频至季度，避免打扰导致彻底退订 | 0 |

**必做两件事**
1. **保留 10% holdout 不触达**——否则无法区分"召回效果"与"自然回流"。
2. **回收流失原因**（一句话调研 + 小额积分）——这比多召回几个人更有长期价值。

**话术模板（一探，零成本且转化不低）**
> 你有 1,280 积分将在 15 天后过期（约值 12.8 元）。
> 现在可直接兑换【XX】或抵扣订单金额 👉 一键兑换

## 剧本 10｜付费会员续费

| 时点 | 动作 |
|---|---|
| T-30 | **年度省钱账单**："过去一年你通过会员省了 XXX 元"（**这是续费的决定性触点**） |
| T-15 | 续费专属优惠（老会员价 / 续费送积分） |
| T-7 | 权益到期提醒 + 未使用权益提示（"你还有 2 张免运费券未用"） |
| T-1 | 最后提醒（自动续费用户须**以显著方式提示**，符合消保条例要求） |
| T+7 | 未续费挽留：限时回归价 + 一句话调研"为什么不续了" |
| T+30 | 转入沉睡池，季度触达 |

**坑**：到期无任何动作 = 白白流失一批本可挽回的会员。这是付费会员运营最低级也最常见的失误。

## 剧本 11｜生日营销（**性价比最高的情感触点之一**）

| 项 | 内容 |
|---|---|
| **触达节奏** | 生日前 7 天预告 → 生日当天祝福 + 权益 → 生日后 3 天到期提醒 |
| **权益** | 生日券（有效期 15 天，覆盖生日前后）、双倍积分、免费小礼、到店领取的礼物 |
| **要点** | ① 到店领取能带动连带消费；② 券有效期跨越生日前后，别只给当天；③ 加一句真人感的祝福，不要模板腔 |
| **预期指标** | 生日月消费提升（通常显著高于平月） |
| **坑** | 只发一条祝福不给权益 = 无效；只给券不给情感 = 变成又一次促销 |

## 剧本 12｜里程碑纪念（低成本高情感）

触发时机与内容：

| 触发 | 动作 |
|---|---|
| 入会满 1 年 | 年度报告（你的第一单是 XX、今年买了 X 次、省了 XX 元）+ 纪念徽章 |
| 第 10 次购买 | 专属称号 + 小礼 + 手写感卡片 |
| 累计消费达 1 万 | 升级提示 + 感谢信 + 专属客服 |
| 品牌周年 | 全员小礼 + 老会员额外权益（按入会年限差异化） |

> 这类动作的成本极低，但对 NPS 和情感忠诚的影响远超同等成本的折扣。
> **年度报告尤其值得做**——它把"你和品牌的关系"具象化了，社媒传播性也强。

## 通用执行清单（每条剧本上线前核对）

- [ ] 人群定义写成了可执行的圈选规则（字段 + 阈值），而不是形容词
- [ ] 设置了退出条件（已转化即停止后续触达）
- [ ] 纳入统一频控（≤2 次/周、≤6 次/月）
- [ ] 保留了 5–10% holdout 对照组
- [ ] 定义了成功指标与观察窗口
- [ ] 权益成本已计入总成本率
- [ ] 触达渠道符合合规要求（可退订、可关闭个性化推荐）
- [ ] 话术经过品牌调性改写，不是模板腔

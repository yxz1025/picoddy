# 权益弹药库

> **列说明**
> - **成本**：公司实际付出（🟢低 / 🟡中 / 🔴高），已考虑边际成本
> - **感知**：用户主观价值感（★–★★★）
> - **核销率**：预计使用率区间（`行业经验值·待替换`）
> - **象限**：对应四象限（★★★主力 / ★★稀缺 / ⚠陷阱 / ✗淘汰）
>
> **选品原则：优先挑「成本🟢 + 感知★★★」的行，它们是体系的性价比核心。**

---

## 一、折扣让利类（最常用，也最容易做错）

| 权益 | 成本 | 感知 | 核销率 | 象限 | 备注 |
|---|---|---|---|---|---|
| 全场固定折扣（如 9.5 折） | 🔴 | ★ | 100% | ⚠陷阱 | **最差权益**：成本按 GMV 线性增长，用户无感，且训练价格敏感。除非毛利 >65% 否则不做 |
| 会员专享价（部分单品） | 🟡 | ★★★ | 30–60% | ★★★ | 只对选定 SKU 让利，成本可控，"专享"感强。**推荐替代全场折扣** |
| 阶梯满减（满 X 减 Y） | 🟡 | ★★ | 20–40% | ★★ | 直接拉客单价，门槛设在客单价 1.3–1.5 倍处 |
| 生日月专属折扣/券 | 🟢 | ★★★ | 25–45% | ★★★ | 时点专属感强，成本可控。**必配"生日前 7 天提醒"** |
| 每月固定券包 | 🟡 | ★★ | 15–35% | ★★ | 制造月度回访理由；未领取的券成本为零 |
| 免运费（包邮） | 🟢🟡 | ★★★ | 40–80% | ★★★ | **感知价值远高于实际成本**（用户按自己寄件价感知）。电商第一权益 |
| 无门槛小额券 | 🟡 | ★ | 40–70% | ✗淘汰 | 低感知、纯损耗，且吸引羊毛用户 |
| 退货运费险/免费退换 | 🟡 | ★★★ | 8–20% | ★★★ | 服饰美妆的转化神器；降低决策门槛，实际使用率不高 |
| 价格保护（买后降价补差） | 🟡 | ★★★ | 3–10% | ★★★ | 消除"买早了亏"的顾虑，实际触发率很低 |
| 以旧换新补贴 | 🔴 | ★★★ | 5–15% | ★★ | 3C/家电专用，可与厂商共担成本 |

## 八、**必须避开的权益反模式**

| 反模式 | 为什么错 |
|---|---|
| 权益清单堆到 15 项 | 用户记不住任何一项；成本翻倍，感知不变 |
| 相邻等级只差折扣点位 | 等级失去意义，升级无动力 |
| 权益需要复杂操作才能享受 | 每多一步操作，核销率掉一半 |
| 权益规则写得像法律条文 | 用户看不懂 = 不敢用 = 白发 |
| 高成本权益不设资格门槛 | 一定被薅；必须绑定等级/消费门槛/频次上限 |
| 只在入会时给一次大礼包 | 吸引羊毛党，留存极差。**入会礼要小，持续权益要稳** |
| 权益无到期提醒 | 大量权益静默过期 → 用户认为"这个会员没用" |
| 全部权益都要用户"领取" | 应尽量自动生效（隐形化），减少操作成本 |

## 九、权益组合模板（可直接套用）

### 模板 A｜高频低客单（茶饮/咖啡/便利店）
```
L1：消费积分 + 生日券
L2：积分 1.2× + 每月一张升杯券 + 生日双倍积分   ← 记忆点：免费升杯
L3：积分 1.5× + 每月两张升杯券 + 免排队 + 新品免费试饮 ← 记忆点：新品免费试
```

### 模板 B｜中频中客单（美妆/服饰/母婴）
```
L1：消费积分 + 生日礼
L2：积分 1.2× + 免运费 + 延长退换 30 天         ← 记忆点：无忧退换
L3：积分 1.5× + 免运费 + 延长退换 90 天 + 专属顾问 + 限量优先购 ← 记忆点：限量先买权
```

### 模板 C｜低频高客单（3C/家电/家装/汽车）
```
L1：消费积分 + 延保 3 个月
L2：延保 12 个月 + 免费上门检测 + 专属客服        ← 记忆点：多保一年
L3：延保 24 个月 + 免费安装/保养 + 以旧换新加价 + 专属顾问 ← 记忆点：终身服务管家
```

### 模板 D｜付费会员权益包
```
必备三件套：
  ① 高频省钱权益（免运费/每单立减）—— 保证用户能回本
  ② 生态联合权益（视频/音乐/外卖）—— 拉高感知价值
  ③ 服务特权（专属客服/优先发货）—— 制造身份差异
再加：
  ④ 会员中心显示「你今年已省 XX 元」—— 续费的决定性因素
```

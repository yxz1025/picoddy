# 会员等级与权益体系设计

## 一、第一步：会员制形态选型

不要一上来就设计等级。先选形态——**选错形态，后面所有设计都是白做。**

| 形态 | 核心机制 | 适配条件 | 主要收益 | 主要风险 |
|---|---|---|---|---|
| **免费等级制** | 累计消费/成长值升级，享阶梯权益 | 中高频、毛利中等以上 | 提频次、提客单、沉淀数据 | 权益成本随会员数线性增长 |
| **付费订阅制** | 预付年费换确定性权益包 | 高频刚需、用户对省钱确定性敏感 | 预收现金流、锁定复购、心理沉没成本 | 用户不回本 → 续费崩塌 |
| **储值制 / 次卡** | 预充值送权益/折扣 | 到店履约、服务型、高频 | 现金流、锁客 | **预付卡合规**、履约风险、退卡纠纷 |
| **身份社群制** | 邀请制/资格制，卖专属与身份 | 高客单、低频、强品牌 | 高毛利、口碑、情感忠诚 | 规模天花板低、运营重 |
| **混合制（双轨）** | 免费等级 + 付费加速包 | 规模大、人群分层明显 | 兼顾覆盖与变现 | 复杂度高，用户容易看不懂 |

### 选型决策树

```
① 年购买频次 < 1.5？
   → 是：不建议做完整等级体系。做「服务权益 + 转介绍 + 客户资产沉淀」。
   → 否：继续

② 用户是否对"确定性省钱"高度敏感（价格是首要决策因素）？
   → 是 且 频次 ≥12次/年 → 付费订阅制（或双轨制）
   → 否：继续

③ 是否到店履约的服务型生意？
   → 是 → 储值 / 次卡（务必先过预付卡合规）
   → 否：继续

④ 客单价 > 2000 且 品牌溢价明显？
   → 是 → 身份社群制（服务权益 + 专属体验）
   → 否 → 免费等级制 + 积分（最通用解）
```

## 二、等级设计

### 2.1 档数

| 会员规模 | 建议档数 | 理由 |
|---|---|---|
| <10 万 | **3 档** | 档数多于人群，每档人数太少无法差异化运营 |
| 10–100 万 | **3–4 档** | — |
| >100 万 | **4–5 档** | 最高档可做"邀请制"，制造稀缺 |

> **反模式**：一上来就做 6 档以上。用户记不住，权益被稀释，每档差异感消失。**宁可少一档，把差异做足。**

### 2.2 门槛测算：分位数法（**不要拍脑袋定整数**）

**做法**：取近 12 个月用户的年度累计消费额，做分位数分布，用分位点定门槛。

```
推荐分位锚点（4 档体系）：
  L1 普通会员   → 0（注册即得）
  L2 银卡       → 第 50–60 百分位   （目标覆盖 40–50% 的活跃用户）
  L3 金卡       → 第 80–85 百分位   （目标覆盖 15–20%）
  L4 黑卡       → 第 95–97 百分位   （目标覆盖 3–5%）

3 档体系：
  L1 → 0 ；L2 → 第 60–70 百分位 ；L3 → 第 90–93 百分位
```

**为什么用分位数而不是拍整数**：
- 保证每档有足够人数支撑运营动作；
- 保证门槛"跳得动"——用户在 L1 时看到 L2 门槛，感觉"再买两次就到了"；
- 避免出现 95% 的人卡在最低档的经典失败。

**门槛落定后必须做"取整美化"**：把分位数结果向上取整到有记忆点的数字（如 1888、3888、6888），但偏离原始分位点不超过 ±10%。

**门槛校验三问**：
1. 每档预计人数占比是否落在设计目标区间？
2. 从 L(n) 升到 L(n+1) 需要**多久能达成**？（见下方行业化标准）
3. 该门槛下，该档权益的**单人年化成本**是否 < 该档人群的**年化增量毛利**？（这是成立的底线）

### ⚠️ 低客单高频行业的两条修正（茶饮/咖啡/便利店/快餐必看）

这类业务直接套用"累计金额门槛 + 2–5 笔"的通用标准会**必然翻车**，必须做两处修正：

**修正一：门槛货币改用「成长值」，不要用纯累计金额。**
客单价 20 元的业务，若把门槛设在 288 元，换算下来要买 13 笔——用户看到金额门槛毫无感知。
且纯金额门槛会激励"单次多买"，而这类业务真正要的是**回店频次**。

```
推荐公式：成长值 = 消费金额 × 1 + 到店次数 × K
  K 取值 ≈ 客单价的 0.4–0.6 倍（客单 22 元 → K 取 10）

效果：把"来一次"本身定价，等级体系直接牵引频次而不是客单。
     用户的心智也从"我花了多少钱"变成"我来了多少次"——后者对高频业务友好得多。
```

**修正二：升级难度按「月数」衡量，不按「笔数」。**

| 业务频次 | 升级难度的合理标准 |
|---|---|
| 高频（月均 ≥3 次） | **2–3 个月可达**（可能是 8–12 笔，笔数多不是问题） |
| 中频（月均 1–2 次） | 3–5 个月可达（约 4–8 笔） |
| 低频（季度级以下） | 按"2–4 次购买"衡量，此时笔数标准才适用 |

> 判断依据：用户感知的是**时间跨度**而非交易笔数。每天一杯咖啡的人，买 12 笔只要两周，毫无难度感；
> 一年买两次家电的人，买 3 笔要一年半，直接放弃。**同样的笔数，在不同频次业务里意味着完全不同的难度。**

### 2.3 成长值（何时需要）

**只有当"消费额"不足以刻画用户价值时才引入成长值**（如需要奖励非交易行为、需要跨品类归一、需要抑制退货刷单）。

```
成长值 = w₁ × 消费金额贡献
       + w₂ × 频次贡献
       + w₃ × 非交易行为贡献（评价/内容/邀请/签到/授权）
       − w₄ × 负向行为（退货/取消/客诉恶意）

推荐初始权重：w₁ 60–70%，w₂ 15–20%，w₃ 10–20%，w₄ 视风控需要

铁律：
  · 成长值公式必须对用户可见、可预测（用户要能算出自己怎么升级）
  · 退货必须扣回对应成长值（否则必被刷）
  · 非交易行为的权重上限建议 ≤20%，否则等级与商业价值脱钩
```

### 2.4 保级与降级（**没有降级的等级会贬值**）

| 机制 | 做法 | 适用 |
|---|---|---|
| **年度清零重算** | 每年 1 月按上年度消费重定级 | 简单直观，最常用 |
| **滚动 12 个月** | 任意时点看最近 12 个月累计 | 体验平滑，无"年初跳水"，但用户较难理解 |
| **保级门槛 < 升级门槛** | 保级只需升级门槛的 60–70% | 降低老客焦虑，强烈推荐 |
| **降级缓冲** | 掉级前 30 天提醒 + 给一次"冲刺任务"机会 | 把降级风险转化为一次促活机会 |
| **终身等级** | 累计消费达极高阈值后永久保级 | 仅用于最高档，制造终极目标 |

> **降级提醒是最高 ROI 的触达之一**：损失厌恶比获得动机更强。"你还差 XXX 元保住金卡权益"的效果，通常显著优于"再买 XXX 元升级"。

## 三、权益设计

### 3.1 核心工具：感知价值 / 实际成本 四象限

```
              高感知价值
                   │
   ★★★ 主力区       │      ★★ 稀缺区
   高感知·低成本     │      高感知·高成本
   （体系的灵魂）     │      （限量投放给高层级）
   例：生日礼、专属客服 │      例：免费换新、专车接送
   优先购、免运费、    │
   免费退换、积分翻倍   │
───────────────────┼───────────────────
   ✗ 淘汰区         │      ⚠ 陷阱区
   低感知·低成本     │      低感知·高成本
   （砍掉，别占位）    │      （立刻砍掉）
   例：无门槛 1 元券   │      例：全场 9.5 折
   电子刊物、无用徽章   │      （成本巨大但用户无感）
                   │
              低感知价值
```

**设计纪律**：
1. 每档权益 **3–6 项**，不超过 6 项。超过后用户记不住，且成本失控。
2. **每档必须有一个"记忆点权益"**——用户能一句话说出来的那个（"这个卡就是能免费退换货的"）。
3. **相邻档位的差异必须一眼可辨**。若 L2 和 L3 的差别只是折扣从 9.5 折到 9.3 折，等级就失效了。
4. **通用折扣是最差的权益**：成本高、无差异、伤品牌、且训练用户等打折。除非毛利极高，否则不做全场折扣。

### 3.2 权益类型清单（详见 `@references/benefit-library.md`）

七大类：`折扣让利` / `积分权益` / `服务权益` / `体验权益` / `身份权益` / `内容权益` / `生态权益`

**优先级建议**：服务权益 > 体验权益 > 身份权益 > 积分权益 > 折扣让利。
理由：前三类的**感知价值/成本比**最高，且不训练用户的价格敏感。

### 3.3 权益成本测算（**必做**）

```
单档单人年化权益成本 = Σ (权益 i 单次成本 × 预计年使用次数 i × 核销率 i)

关键：一定要乘核销率。按 100% 核销测算会严重高估成本、砍掉本该保留的好权益；
      但预算规划必须按"高核销情景"做压力测试（核销率取上限值）。

三情景测算（报告中必须给三档）：
  保守情景：核销率取基准值 × 0.6
  基准情景：核销率取基准值
  压力情景：核销率取基准值 × 1.8（且封顶 100%）
```

用 `scripts/tier_calc.py` 完成分位数门槛测算 + 三情景成本测算。

## 四、付费会员：定价与回本模型

### 4.1 定价四步法

```
Step 1  测算"用户可感知年省额" S
        S = Σ(权益 i 的用户感知价值 × 预计年使用次数)
        注意：用「用户感知价值」而非「公司成本」。免运费的公司成本可能 5 元，
              用户感知价值是 10 元（他自己寄要 10 元）。

Step 2  按心理回本倍数 k 反推价格上限
        价格 ≤ S / k
        k：价格敏感型 3–5；中度 2–3；身份服务型 1–1.5

Step 3  校验公司侧单位经济
        单会员年毛利增量 = (会员年 GMV × 毛利率 − 非会员对照组年 GMV × 毛利率)
                          + 会员费 − 权益履约成本
        要求 > 0，且回本周期 ≤ 12 个月

Step 4  设计价格锚点
        · 月付 + 年付双档，年付标注"相当于每月 X 元"（年付渗透率是关键）
        · 首年体验价 + 次年原价（必须在购买页显著提示续费价格）
        · 88/99/128/199/298 是记忆度较高的价格带
```

### 4.2 续费率的三个决定因素（按重要性排序）

1. **用户真的回本了吗** → 必须在会员中心持续展示「你今年已省 XX 元」，并在续费前 30 天推送年度省钱账单。
2. **高频权益有没有被用上** → 上线后 7/30 天内未使用任何权益的会员，续费率会断崖下跌。必须设「权益激活流程」：入会 24h 内引导使用第一项权益。
3. **到期有没有挽留动作** → 到期前 30/7/1 天三段式提醒 + 未续费后 7 天的挽留优惠。

### 4.3 自动续费的合规硬约束 🔴

《消费者权益保护法实施条例》（2024 年 7 月 1 日施行）第十条第二款：经营者采取自动展期、自动续费等方式提供服务的，**应当在消费者接受服务前和自动展期、自动续费等日期前，以显著方式提请消费者注意**。

方案中必须包含：购买页显著告知 + 续费日前提醒 + 便捷的取消入口。详见 `campaign-playbook/references/compliance-redlines.md`。

## 五、创新设计模块

### 5.1 赛季制成长（Battle Pass 机制）

**解决的问题**：传统等级体系一旦到顶，用户就失去目标；且新客永远追不上老客。

```
双轨结构：
  永久轨（Lifetime Tier）：累计消费决定，只升不降 → 承载身份与长期价值
  赛季轨（Season Track）：每季度/半年清零重置，完成任务解锁奖励 → 承载短期活跃

赛季轨设计：
  · 周期 90 天，10–15 个节点，节点奖励递增
  · 免费轨 + 付费加速轨（付费轨即付费会员的变体，转化率通常优于直接卖会员卡）
  · 每个节点的任务要覆盖多种行为：购买、复访、评价、邀请、跨品类尝鲜
  · 赛季结束保留一个"荣誉标记"（勋章/称号），沉淀情感资产
```

适配：高频消费、有 App/小程序阵地、目标用户偏年轻的品类。

### 5.2 情感忠诚三件套

行业研究指出，与品牌形成情感连接的顾客，其生命周期价值显著高于"满意但无情感连接"的顾客。仅靠折扣积分只能买到价格忠诚。

| 组件 | 做法 | 成本 |
|---|---|---|
| **里程碑纪念** | 入会周年、第 10 次购买、消费满 1 万，自动触发专属纪念（手写卡/数字纪念卡/专属称号） | 极低 |
| **身份可见性** | 等级标识在下单页/客服会话/包裹上可见；线下门店叫得出等级称呼 | 极低 |
| **共创参与感** | 新品投票权、内测资格、命名权、会员共创委员会 | 低，且产生真实产品价值 |

**这三件套的成本几乎可以忽略，但对续费率和 NPS 的影响远超同等成本的折扣。**优先做。

### 5.3 Next-Best-Benefit：千人千面权益引擎

**解决的问题**：统一权益包必然对一部分人过度补贴、对另一部分人吸引力不足。

```
做法（分三阶段实施，匹配数据能力）：

阶段一（无算法）：规则化 —— 按 RFM 分群 × 品类偏好，配 4–6 套权益组合，人工映射
阶段二（有 CDP）：打分制 —— 对每个权益给每个用户打"预期使用概率 × 预期增量毛利"分，取 Top N 推送
阶段三（有算法）：增益模型（Uplift Model）—— 只对"发了才会来"的说服型人群投放

  增益四象限：
    确定会买（Sure Thing）    → 不投放（省下的就是净赚）
    可被说服（Persuadable）   → 重点投放  ★★★
    不可打动（Lost Cause）    → 不投放
    投了反而跑（Sleeping Dog）→ 禁止投放（打扰导致退订/流失）
```

> **这是会员运营降本增效最大的单点杠杆。**多数企业的会员补贴，有相当比例花在了"确定会买"的人身上。哪怕只做到阶段一，也能省下可观预算。

### 5.4 权益"隐形化"

成熟体系的趋势：让用户**无需操作即可享受**权益（自动最优券、自动免运费、自动升级服务），而不是让用户去"找券、领券、算怎么最省"。
减少操作成本 = 提升感知价值，且降低客诉。

## 六、老体系迁移方案（**升级改造项目必写**）

这是实操中最容易翻车、也最少人写的部分。必须给出：

1. **积分换算比例**：新旧积分单位价值不同时，给出换算公式与取整规则。**只能上调不能下调用户的既有价值**（下调必然引发投诉与舆情）。
2. **等级映射规则**：旧等级 → 新等级的对照表。**老会员只升不降**，用"保护期"（如 12 个月）过渡。
3. **老会员安抚包**：给出一次性补偿（如换新礼包 + 保护期），并在沟通中明确"你的权益只多不少"。
4. **对外沟通话术与节奏**：T-30 天预告 → T-7 天详解 → T 日切换 → T+7 天答疑。三个必答问题：我的积分怎么办？我的等级会掉吗？我原来的权益还有吗？
5. **客诉预案**：预判 Top 5 投诉点，准备标准应答与补偿口径，客服培训材料。
6. **灰度策略**：先对 5–10% 用户灰度，观察 2 周核心指标（客诉率、活跃度、核销率）再全量。

> **积分清零/规则变更的合规提醒**：积分作为用户既得利益，规则变更与清零必须**提前、显著地告知**。未经充分告知即清零，可能被认定为侵害消费者权益或构成不公平格式条款。详见 `points-economy/references/points-accounting.md` 与合规红线清单。

# 会员体系诊断

任何会员方案的第一步。**没做过这一步就直接给体系设计，是不专业的。**

## 一、诊断的三个层次

| 层次 | 要回答的问题 | 数据来源 |
|---|---|---|
| **L1 业务适配度** | 这门生意到底适不适合做会员？做哪种会员？ | 访谈（复购周期、客单价、毛利、频次） |
| **L2 体系健康度** | 现有体系哪里坏了？坏在设计还是执行？ | 现有规则文档 + 11 项健康度指标 |
| **L3 资源可行性** | 想做的事，钱、数据、系统、人撑不撑得住？ | 访谈（预算、CDP/CRM、团队、执行力） |

---

## 二、L1 业务适配度：先判断「该做哪种会员」

**这是最容易被跳过、却决定成败的一步。**用两个维度定位：

```
                 高频（月均 ≥1 次）
                        │
   ② 付费订阅制          │        ① 免费等级制 + 积分
   （用省钱确定性锁客）    │        （用成长感和特权锁客）
   例：商超/生鲜/咖啡      │        例：茶饮/快消/日用电商
                        │
低客单 ───────────────────┼─────────────────── 高客单
（<200元）                │                （>500元）
                        │
   ③ 储值制 / 次卡        │        ④ 身份社群制 + 服务权益
   （用预付锁定现金流）     │        （用专属服务与身份锁客）
   例：美业/洗车/健身      │        例：奢品/家装/汽车/高端医美
                        │
                 低频（季度级以下）
```

**判定规则（按顺序检查）：**

1. **年购买频次 < 1.5 次** → 会员体系对复购的杠杆很弱。诚实告诉用户：优先做转介绍 + 客户资产沉淀，而不是等级积分体系。
2. **毛利率 < 20%** → 权益成本空间极窄。走"服务型权益/身份权益"路线，慎用折扣和积分。
3. **高频 + 低客单 + 高毛利** → 积分 + 任务 + 游戏化的最佳土壤。
4. **中高客单 + 中频 + 用户对"确定性省钱"敏感** → 付费会员制的最佳土壤（付费会员的本质是：用户预付一笔钱，购买"未来一年都能省钱"的确定性）。
5. **强服务属性 + 到店履约** → 储值 / 次卡 + 服务权益，注意预付卡合规（见 `campaign-playbook/references/compliance-redlines.md`）。

## 三、L2 体系健康度：11 项核心指标体检

要求用户提供以下数据；拿不到的，标注为「数据缺口」写进报告。

| # | 指标 | 计算口径 | 健康信号 | 危险信号 |
|---|---|---|---|---|
| 1 | 会员渗透率 | 会员数 / 总客户数 | 持续上升 | 停滞或注册后无二次行为 |
| 2 | 会员 GMV 占比 | 会员贡献 GMV / 总 GMV | 显著高于渗透率 | ≈ 渗透率（说明会员身份没带来增量） |
| 3 | 会员客单价倍数 | 会员 ATV / 非会员 ATV | > 1.2 | ≤ 1.0 |
| 4 | 会员复购率 | 期内复购会员 / 期初活跃会员 | 逐 Cohort 抬升 | 逐 Cohort 走低 |
| 5 | 等级分布 | 各等级人数占比 | 金字塔且中间层可流动 | 95% 卡在最低档（门槛过高） |
| 6 | 升级率 / 降级率 | 期内升级人数 / 期初人数 | 升级率 5–15% | 升级率 <2%（体系无牵引力） |
| 7 | 权益核销率 | 已核销权益人次 / 已发放 | 各项 > 15% | < 5%（权益不匹配或用户不知道） |
| 8 | 积分发放成本率 | 积分发放金额 / GMV | 在预算带内 | 无上限、随活动无序膨胀 |
| 9 | 积分核销率 | 已核销积分 / 已发放积分 | 40–70% | <20%（积分无用）或 >90%（成本失控） |
| 10 | 积分沉淀率 (breakage) | 过期未用积分 / 已发放 | 有稳定可预测的值 | 未做估算（负债不可控） |
| 11 | 会员流失率 | 期内转沉睡会员 / 期初活跃 | 稳定或下降 | 上升且无预警机制 |

> **重要**：行业研究表明，相当比例的忠诚计划积分长期未被使用，形成规模巨大的"沉睡积分"。指标 9/10 一旦失控，体系要么变成用户眼里的"假福利"（核销率过低），要么变成公司账上的"隐形负债"（发行无节制）。这两项是体检重点。

### 常见病症 → 病因速查

| 症状 | 最可能的病因（按概率排序） |
|---|---|
| 积分没人用 | ① 兑换门槛过高 ② 兑换品无吸引力 ③ 用户不知道有多少分 ④ 积分价值感知不清晰（没告诉用户 100 分 = 多少钱） |
| 等级形同虚设 | ① 门槛脱离真实分布 ② 高等级权益与低等级差异不明显 ③ 无降级机制导致等级贬值 ④ 等级不可见（用户看不到自己在哪、离下一级多远） |
| 会员不活跃 | ① 只在交易时才被想起（无非交易触点） ② 触达渠道单一 ③ 权益是"打折"而非"专属" |
| 权益成本失控 | ① 无成本率上限 ② 权益按"竞品有我也要有"堆砌 ③ 高价值权益被低价值用户薅走（缺资格门槛） |
| 会员数增长但 GMV 没涨 | ① 注册礼吸引的是羊毛用户 ② 补贴了本来就会买的人（无增量） |
| 付费会员续费率低 | ① 用户没回本（省的钱 < 会员费） ② 权益使用率低（没提醒） ③ 到期无挽留动作 |

## 四、L3 资源可行性：四项边界确认

1. **成本边界**：年度会员预算，或可接受的**成本率上限**（权益+积分总成本占 GMV 或占毛利的百分比）。这是所有设计的天花板，必须问出来；问不出来就给建议区间让用户选。
2. **数据边界**：有无统一 ID？有无 CDP/CRM/SCRM？能否做人群圈选、实时触发、A/B 分流？——决定方案是"精细化分层"还是"粗颗粒分层"。
3. **系统边界**：会员系统是自研/SaaS/无？积分能否实时计算？线上线下积分是否互通？——决定方案的实现排期。
4. **组织边界**：几个人执行？门店店员是否参与推广（决定线下渗透率）？能否月度迭代？

> **原则**：方案的复杂度必须匹配团队的执行能力。给一个 3 人团队设计需要 12 个自动化触发流程的方案，等于没给方案。

## 五、访谈执行方法

1. 严格按 Agent 主提示词中的**交互协议**执行：第一轮 6 题、第二轮 ≤5 题，全部带选项与默认值。
2. 用户嫌麻烦时，立即启用 `references/industry-benchmarks.md` 的行业默认值，先出方案，把假设单列成表。
3. 详细问题库与"每题为什么问、答案如何改变方案"见 `@references/interview-bank.md`。
4. 行业基准与缺省假设值见 `@references/industry-benchmarks.md`。

---

## 六、诊断产出物（写进报告第 2 章）

1. **业务适配度结论**：该做哪种会员制 + 一句话理由。
2. **健康度体检表**：11 项指标的现状值 / 基准值 / 差距 / 判定（🟢正常 🟡关注 🔴危险）。
3. **问题优先级矩阵**：按「影响面 × 修复成本」四象限排布，明确"先修哪三个"。
4. **数据缺口清单**：为把结论坐实，还需要补哪些数据、从哪个系统取、字段是什么。
5. **假设登记表**：所有代入的行业默认值，逐条列出，标注"待客户替换"。

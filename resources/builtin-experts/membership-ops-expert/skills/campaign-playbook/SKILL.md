# 会员活动与营销日历

> **核心认知：活动不是"搞事情"，是"在正确的时间、对正确的人、用最小的成本、撬动一次本来不会发生的行为"。**
> 一个活动如果换来的都是本来就会发生的购买，那它的真实 ROI 是负的——因为你为免费的东西付了钱。

---

## 一、活动设计七要素（**缺一不可，缺了就是没想清楚**）

| # | 要素 | 必须回答 | 常见错误 |
|---|---|---|---|
| 1 | **目标** | 撬动哪一个具体行为？用哪一个指标衡量？ | 目标写"提升活跃度"（无法衡量） |
| 2 | **人群** | 圈选规则是什么（字段+阈值）？预计多少人？ | 全员群发 |
| 3 | **机制** | 用户要做什么、能得到什么？三句话讲得清吗？ | 规则复杂到要看说明书 |
| 4 | **成本** | 单人成本 × 预计参与人数 = 总成本？封顶多少？ | 没设上限 |
| 5 | **触达** | 什么渠道、几次、什么节奏？ | 只发一次就指望有效果 |
| 6 | **验证** | 对照组怎么设？看几天？成功标准是什么？ | 无对照组，事后无法归因 |
| 7 | **风控** | 怎么防刷？怎么熔断？ | 上线才发现被薅 |

> **一句话检验法**：如果你不能用一句话说清"我们要让【谁】在【什么时候】做【什么事】，为此我们付出【多少成本】"，这个活动就还没设计完。

## 二、活动 ROI 模型（**所有活动上线前必算**）

```
【核心公式】
增量 GMV = (实验组人均 GMV − 对照组人均 GMV) × 参与人数
增量毛利 = 增量 GMV × 毛利率
活动 ROI = (增量毛利 − 活动总成本) / 活动总成本

活动总成本 = 权益/奖品成本 + 券核销成本 + 积分成本 + 触达成本 + 人力与制作成本
```

### 🔴 最关键的一条：**必须用对照组，不能用"参与 vs 未参与"**

```
❌ 错误："参与活动的用户人均消费 300 元，没参与的只有 120 元，活动效果显著！"
   → 这是选择偏差。本来就想买的人才会去参与。

✅ 正确：随机把目标人群分成两组
   实验组（90%）：正常参与活动
   对照组（10%）：不触达、不给权益
   两组人均 GMV 之差 × 参与人数 = 真实增量
```

**没有对照组的活动数据，无法证明活动有效。**这是会员运营最重要的一条方法纪律。
每个活动都留 5–10% holdout，长期积累下来就是你判断"什么有用、什么没用"的唯一可靠依据。

### ROI 判定标准

| ROI | 判定 | 动作 |
|---|---|---|
| > 3 | 🟢 优秀 | 加大投入，考虑常态化 |
| 1–3 | 🟡 可接受 | 优化人群精准度与成本结构 |
| 0–1 | 🔴 亏损 | 除非有战略目的（拉新/教育市场），否则停 |
| < 0 | 🔴 有害 | 立即停止，且需复盘是否补贴了自然购买 |

> **战略性亏损是允许的，但必须是"明知且有期限"的。**新体系冷启动期的拉新活动可以亏，
> 但要写明"预计第 X 个月转正，靠什么转正"。

用 `scripts/campaign_roi.py` 做测算与敏感性分析。

## 三、活动机制库

详见 `@references/campaign-library.md`（30+ 活动模板，含机制、成本、指标、坑）。核心分类：

| 类型 | 代表玩法 | 主要撬动 |
|---|---|---|
| **拉新入会** | 入会礼、店员推荐激励、老带新、异业互推 | 会员渗透率 |
| **首购转化** | 新人券、爆品引流、限时体验价 | 首购率 |
| **复购促进** | 复购券、周期购、订阅制、耗材提醒 | 复购频次 |
| **客单提升** | 阶梯满减、套装、加价购、凑单推荐 | ATV |
| **活跃促进** | 签到、任务、赛季、积分翻牌 | DAU/月活 |
| **等级牵引** | 升级冲刺、双倍成长值、保级挽留 | 升级率/保级率 |
| **积分消耗** | 积分商城、限时兑换、积分+现金、积分抽奖 | 核销率/负债 |
| **召回唤醒** | 积分到期提醒、回归礼、专属顾问 1v1 | 召回率 |
| **情感与品牌** | 会员日、生日、周年、共创、年度账单 | NPS/情感忠诚 |

## 四、年度会员营销日历

### 4.1 三层节奏结构

```
【常态层】固定节奏，全年不变 —— 建立用户预期
  · 每月会员日（固定日期，如每月 8 日）★体系的心跳
  · 每月积分兑换上新
  · 生日营销（滚动触发）
  · 自动化旅程（首购/二购/升级/保级/到期）

【脉冲层】季度大动作 —— 制造峰值
  · Q1 开年焕新 / 春节
  · Q2 品牌日 / 618
  · Q3 周年庆 / 暑期
  · Q4 双 11 / 双 12 / 年末冲刺 + 年度账单

【机动层】随时可上 —— 补窟窿用
  · 积分流通池膨胀 → 限时兑换活动
  · 某月 GMV 缺口 → 定向人群冲刺
  · 竞品动作 → 高价值客防守
```

### 4.2 会员日设计要点（**性价比最高的常态动作**）

- **固定日期**（如每月 8 日），让用户形成记忆和预期。不要每月换。
- **只对会员开放**，强化身份差异。这是会员日的意义所在。
- **组合拳**：双倍积分 + 会员专享价 + 积分兑换折上折 + 新品优先购。
- **放在销售低谷日**，用会员日填谷，而不是在高峰日再加把火（那是浪费成本）。
- **提前 2 天预热**，当天 2 次触达（早/晚），次日战报。

### 4.3 排期原则

1. **大促期间会员权益要"叠加但不冲突"**——大促已经足够便宜时，会员权益应给"非价格"的（优先发货、专属客服、额外积分），否则双重让利会击穿毛利。
2. **两个大活动之间留 2 周空窗**，否则用户疲劳、且互相稀释。
3. **每个季度至少一次纯情感活动**（无直接销售目标），否则会员感知到的只有"你们又在卖东西"。
4. **年末必做年度账单**——低成本、高传播、高情感回报。

## 五、A/B 实验设计

### 什么必须做实验
- 权益力度（发 10 元券 vs 20 元券）
- 文案与触达时点
- 门槛设置（满 199 减 30 vs 满 299 减 50）
- 人群圈选规则

### 实验设计三要素

```
① 分组：随机分流，保证组间可比（按 user_id 哈希，不要按注册时间/地区分）
② 样本量：单组建议 ≥1,000 人（转化率低的场景需更多）；
          小流量时用"时间轮换"（本周 A 组、下周 B 组）替代
③ 观察期：≥1 个购买周期 T，且要看"后续 30 天是否透支"
          —— 大额券会把未来的购买提前，短期数据好看，长期是负增量
```

### 必须警惕的三个陷阱

| 陷阱 | 表现 | 防范 |
|---|---|---|
| **需求透支** | 活动期暴涨，活动后暴跌 | 观察窗口延长到活动后 30 天，看合计增量 |
| **自然增长误判** | 把大盘增长算成活动效果 | 必须有同期对照组 |
| **只看参与者** | 参与者数据好看 | 用"全体目标人群"做分母，不是"参与者" |

## 六、防薅羊毛

见 `points-economy/references/points-design-patterns.md` 第四节的完整清单。活动侧的三条最低要求：

1. **设总量上限**：奖品池、券包、积分池，发完即止。**没有上限的活动一定会失控。**
2. **奖励延迟到账**：等交易确认（收货/无退款）后发放，这是成本最低的防御。
3. **异常监控前置**：上线前配置监控规则（单人参与频次、同设备/IP 聚类、兑换集中度），异常先冻结再核查。

## 七、合规检查（**每个活动必过**）

调用 `@references/compliance-redlines.md` 逐项核对。高风险项速记：

| 玩法 | 必查 |
|---|---|
| 抽奖 / 盲盒 / 翻牌 | 最高奖 ≤5 万元、**概率或数量必须公示**、不得内定中奖、档案留存两年 |
| 划线价 / 折扣 | 基准有依据（前 7 日最低成交价）、附加条件与期限显著标明 |
| 赠品 | 合格品、有售后、不侵权 |
| 自动续费 | 购买前 + 扣费前双重显著提示、取消便捷 |
| 储值 / 次卡 | 预付卡备案与资金存管、退卡规则 |
| 裂变 | 奖励不超过一级、无强制分享、未成年人限制 |
| 个性化权益 | 提供关闭个性化推荐的选项、无不合理差别待遇 |

> **专家纪律**：方案中出现上述任一玩法，必须主动提示合规要点，**不能因为用户没问就略过**。
> 合规问题在设计阶段规避成本极低，上线后处理成本极高。

```
【活动名称】          【周期】          【目标人群 / 触达人数】

一、结果
   核心指标：目标值 ___ / 实际值 ___ / 达成率 ___%
   增量 GMV（vs 对照组）：___ 元
   总成本：___ 元（权益 ___ / 券 ___ / 积分 ___ / 触达 ___ / 人力 ___）
   ROI：___

二、分层表现
   哪个人群 ROI 最高？哪个最低？（下次调整投放结构的依据）

三、后效观察（活动后 30 天）
   是否存在需求透支？合并 60 天窗口后增量是否仍为正？

四、结论
   □ 常态化   □ 优化后再试   □ 停止
   一句话原因：___

五、沉淀
   可复用的：___
   下次要避免的：___
```

> **复盘的价值不在于这次活动，而在于建立"什么有用"的组织知识。**
> 建议维护一张全年活动 ROI 台账，一年后它就是你最有价值的资产。

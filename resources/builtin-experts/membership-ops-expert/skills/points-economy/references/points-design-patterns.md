# 积分玩法模式库

> 每个玩法给出：**机制 / 撬动的行为 / 成本量级 / 落地要点 / 常见坑**。
> 选用原则：**先备齐出口，再上发放类玩法。**没有出口就加大发放，等于加速体系失效。

---

## 一、发放类玩法（把积分发出去，撬动行为）

### 1. 每日签到
- **机制**：连续签到递增积分，断签重置；第 7 天给大额奖励
- **撬动**：日活、复访、习惯养成
- **成本**：低（单人日均 1–5 分）
- **要点**：连签奖励曲线要陡（第 7 天 = 前 6 天之和），断签给一次"补签卡"降低挫败
- **坑**：签到只带来"打开 App"，不带来消费。必须在签到页嵌入转化入口（今日推荐/签到专享价），否则是无效日活

### 2. 任务中心
- **机制**：日/周/月任务，完成得积分
- **撬动**：定向行为（浏览新品、加购、评价、分享、跨品类）
- **成本**：中（可精确控制）
- **要点**：任务要与业务目标绑定（想推新品类就出"首购新品类"任务）；同时在线任务 ≤5 个
- **坑**：任务太多 → 用户疲劳；任务太易 → 变成纯薅羊毛

### 3. 积分倍率（等级/会员日/品类/时段）
- **机制**：特定条件下积分翻倍
- **撬动**：升级动机、峰谷调节、品类渗透、渠道迁移
- **成本**：中高（需设池上限）
- **要点**：**这是最灵活的成本阀门**。基础系数保守，弹药全放倍率
- **坑**：大促无上限加倍 → 单月成本率暴增。必须设活动池与熔断

### 4. 首单/入会礼
- **机制**：注册或首购送积分
- **撬动**：入会转化、首购
- **成本**：低–中
- **要点**：**入会礼要小、要即时可用**（送 100 分不如送一张"满 50 减 10"的即时券 + 50 分）
- **坑**：入会礼过大 → 吸引羊毛党，留存极差。**衡量标准是次月复购率，不是入会人数**

### 5. 行为价目表（推荐）
- **机制**：把好评、晒单、邀请、授权、跨品类等行为逐项定价
- **撬动**：全部非交易的价值行为
- **成本**：可精确控制
- **要点**：定价 ≤ 你原本获取该行为的成本 × 60%
- **坑**：定价过高会引来专业刷手；必须配审核（如晒单需人工/AI 过审后到账）

## 二、消耗类玩法（把积分收回来，这才是重点）

### 6. 积分商城
- **选品四原则**：
  1. **自有商品优先**（售价高、成本低、还能带动连带）
  2. **高感知低成本**（小样、周边、体验券、联合会员）
  3. **有大有小**（低门槛品让新会员立刻能兑，高价品给攒分目标）
  4. **定期上新**（每月至少换 20% 的品，否则用户不再来看）
- **坑**：商城全是"用不上的赠品" → 核销率极低；商城长期不上新 → 变成死页面

### 7. 积分 + 现金（加价购）
- **机制**：X 积分 + Y 元换购
- **撬动**：**消化积分的同时产生实际销售**
- **成本**：低（现金部分覆盖了大部分成本）
- **要点**：**积分体系里 ROI 最高的出口之一，务必设计**
- **坑**：现金部分定价过高会被视为"套路"

### 8. 积分抵现
- **机制**：结算时按比例抵扣
- **要点**：**必须限比例**（建议 ≤10–20% 订单额），否则等于全面打折
- **坑**：不限比例 + 高积分余额用户 = 大额亏损订单

### 9. 限时兑换活动
- **机制**："本周积分五折兑""积分日"
- **撬动**：集中消化流通池
- **要点**：当流通池连续膨胀时的**急救手段**
- **坑**：过于频繁会让用户永远等打折兑换

### 10. 积分抽奖 / 翻牌
- **机制**：消耗积分换抽奖机会
- **撬动**：高效消耗积分（消耗量远大于奖品成本）
- **成本**：低（奖品池可控）
- **⚠️ 合规**：属于有奖销售，**最高奖金额不得超过五万元**，且须公示奖项种类、参与条件、开奖方式、**奖品数量或中奖概率**、兑奖方式与时限；不得虚构奖项或内定中奖；相关档案须留存两年
- **坑**：概率不公示 = 违规；"必中"文案与实际不符 = 虚假宣传

### 11. 积分捐赠 / 公益
- **机制**：积分兑换为公益捐赠
- **成本**：低
- **价值**：低成本消化积分 + 品牌形象 + 情感连接
- **坑**：必须真实捐赠并公示去向，否则是重大声誉风险

### 12. 积分兑权益（非商品）
- **机制**：积分换服务（免运费卡、延保、优先权、专属活动名额）
- **要点**：**边际成本最低的出口**，优先设计
- **坑**：权益要"看得懂、用得上"，复杂规则会让用户放弃

## 三、游戏化玩法

### 13. 成长进度可视化
- **机制**：进度条显示"距下一级还差 XXX"
- **价值**：**几乎零成本，对升级率的提升最直接**
- **要点**：必须在会员中心首屏、订单完成页出现

### 14. 里程碑与成就徽章
- **机制**：累计消费/次数/品类解锁徽章
- **成本**：接近零
- **价值**：情感忠诚的低成本抓手
- **要点**：徽章要可展示、可分享，最好带一点稀缺性

### 15. 赛季制（Battle Pass）
- **机制**：90 天赛季，节点任务解锁奖励；免费轨 + 付费加速轨
- **价值**：解决"到顶即无动力"，且付费轨的转化率通常优于直接售卖会员卡
- **要点**：赛季结束保留荣誉标记，沉淀情感资产
- **坑**：任务设计过重 → 用户中途放弃；节点奖励要前密后疏，保证早期正反馈

### 16. 组队 / 助力
- **机制**：邀请好友组队完成任务共享奖励
- **撬动**：拉新、社交裂变
- **坑**：**注意平台规则与法律边界**——不得设置"必须拉够 N 人才能提现/领取"的诱导性设计，避免被认定为虚假宣传或不当营销；不得利用未成年人诱导传播

## 四、防薅羊毛（**上线前必做**）

| 风险 | 手法 | 防御 |
|---|---|---|
| 批量注册领新人积分 | 手机号池、接码平台 | 设备指纹 + 实名/支付验证 + 新客积分延迟到账（首单确认收货后发放） |
| 下单得分后退货 | 刷单退货 | **退货同步扣回积分**；扣成负数时冻结账户直至补足 |
| 拆单刷积分 | 大单拆多单 | 单日单用户积分上限 + 同收货地址聚类监控 |
| 虚假评价刷分 | 复制粘贴好评 | 评价积分需过审后到账；图文重复度检测 |
| 邀请自己 | 小号互邀 | 邀请奖励绑定"被邀请人首单实付且未退款" |
| 积分套现 | 兑换高流通性商品倒卖 | 高价值兑换品限购、限等级、限频次；避免选择强流通性商品（如通用充值卡） |
| 撸活动积分池 | 脚本秒杀 | 活动池上限 + 人机验证 + 单人参与次数上限 |

**风控三原则：**
1. **奖励延迟到账**（等交易确认完成），是成本最低、最有效的防御。
2. **高价值出口必须有资格门槛**（等级/历史消费/实名）。
3. **先监控后处罚**：上线前先配置异常监控规则（单人积分增速、同 IP/设备聚类、兑换集中度），出现异常先冻结再核查。

## 五、玩法组合模板

### 模板 A｜积分体系冷启动（0→1，前 3 个月）
```
发放：消费积分(r=1) + 入会礼 100 分 + 好评 200 分
消耗：积分抵现(≤10%) + 3 档低门槛兑换品(500/2000/5000 分)
可视：会员中心显示"你有 XXX 分 ≈ XX 元"+ 进度条
不做：签到、任务、抽奖（先把基础出口跑顺，避免复杂度过载）
```

### 模板 B｜积分体系激活（体系已有但没人用）
```
第 1 步：查核销率与出口 —— 十有八九是出口不足或门槛过高
第 2 步：上线"积分+现金"加价购 + 低门槛兑换品，把最低门槛降到 1–2 次消费可达
第 3 步：全渠道露出积分余额与可兑换提示（订单页、支付成功页、个人中心）
第 4 步：一次"积分五折兑"活动集中消化流通池，并观察核销率变化
第 5 步：再考虑加签到/任务等发放类玩法
```

### 模板 C｜积分成本失控急救
```
① 立刻设月度发行熔断阈值，暂停所有无上限加倍
② 检查抵现比例是否封顶，未封顶立即封顶
③ 排查退货是否扣分、是否存在刷分
④ 用"限时高价值兑换"消化流通池（用低成本高感知的自有商品）
⑤ 重构出口结构：把成本高的兑换品换成"高售价低成本"的自有商品
⑥ 三个月内不得下调用户既有积分价值 —— 只能从发行端调
```

# 系统内置专家包

来源：用户提供的 `~/Documents/experts`，2026-10-30 纳入应用。

完整保留六个专家包的 agents、skills、references、scripts、assets 及包元数据。会员运营专家的副本补充 `schemaVersion: 2` 以兼容宿主加载器，其余包内容保持原样；不修改来源目录。`provenance.json` 记录导入副本的文件数量和摘要。

运行时通过现有专家包加载器读取主指令和声明技能，向模型提供真实 expertRoot / agentFile，技能引用使用包内路径。安装包将本目录放入独立 resources/builtin-experts，供脚本、模板等按真实路径读取；运行时不依赖原作者电脑目录。

项目阶段默认映射：产品管理专家负责需求、产品方案、调研及交付；软件架构师负责技术设计与开发（含 fullstack-dev 技能）；测试专家负责验收。UI／前端、代码审查与会员运营可手动选择。本地项目上下文优先约束阶段范围与本地产物；专家原包涉及的 TAPD 流程不作为必选步骤，不自动同步外部系统。用户关于不执行自动化测试的要求仍优先。

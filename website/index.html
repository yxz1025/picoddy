ABOUT PICODDY

PiCoddy 是什么？

PiCoddy 是基于 Pi Agent 的 AI 工作伙伴，将对话、文件、终端、浏览器与专业技能放进同一个工作台。桌面端在 macOS、Windows 本地运行，云端提供独立的浏览器访问方式。

核心场景包括日常办公中的资料整理、报告写作与数据分析，桌面工作台内的 Word、Excel、PowerPoint 编辑和预览，以及从需求、设计到开发、测试、交付的 Coding 全流程。从源码启动桌面端后，配置自己的模型，再按任务需要接入工具。本项目采用 MIT License，源码已在 GitHub 开放。

QUESTIONS, ANSWERED

开始前，了解这些。

如何从源码开始使用？＋

先获取源码，安装 Node.js 24+ 与根目录、frontend 依赖。分别启动 Vite 和 Electron，在设置中配置自己的模型与 API Key，再用测试文件夹完成第一个任务。完整命令见入门指南。

桌面端和云端有什么区别？＋

桌面端支持 macOS、Windows，使用本地账户和 SQLite，无需企业登录。云端独立部署，依赖企业 CAS、PostgreSQL、OpenSandbox 和存储服务。两端数据不自动同步，云端能力仍有实施与验收中的部分。

使用 PiCoddy 有哪些费用？＋

模型 API、服务器、存储与第三方服务费用由使用者按自己的配置承担。本项目采用 MIT License，源码仓库：github.com/yxz1025/picoddy。

可以修改源码和再分发吗？＋

本项目原创代码采用 MIT License，允许使用、修改、分发和商业使用；分发时须保留版权声明与许可声明，软件按原样提供，不作担保。第三方组件、内置资源与运行时遵循各自许可。

Office 支持多人在线协同吗？＋

当前介绍的是桌面工作台内嵌的 Word、Excel、PowerPoint 预览、编辑与保存，兼容性取决于文档和运行环境。云端能力以云端文档为准，不承诺多人实时协同。

本地运行后，数据还会发送到外部吗？＋

取决于模型和工具配置。使用外部模型 API 或远程连接器时，会按调用需要传输内容。内网运行需要自行准备内网模型、工具及依赖资源。

如何报告问题或贡献代码？＋

可通过 GitHub 仓库的 Issue 提供复现步骤和脱敏日志，通过 Pull Request 提交聚焦的修改并说明验证结果。欢迎访问开源仓库、提交建议或点个 Star。

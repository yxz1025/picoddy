# PiCoddy 开源官网

独立静态站，无构建依赖。在项目根目录启动：

```sh
python3 -m http.server 4178 --bind 127.0.0.1 --directory website
```

访问 http://127.0.0.1:4178 ，入门指南位于 `/guide.html`。可直接打开 HTML 离线阅读；剪贴板功能建议使用 localhost 或 HTTPS，失败时可手动复制。

## 用户流程

首页了解产品能力 → 比较桌面端与独立云端 → 查看入门指南 → 安装依赖并分别启动 Vite / Electron → 配置自己的模型 → 运行测试任务 → 通过公开仓库参与贡献。

官网不再展示商业源码交付报价，也不收集部署需求。复制按钮复制桌面开发命令，保留双终端提示；Windows PowerShell 命令在入门指南中单独说明。桌面端采用本地账户，云端仍需企业 CAS、数据库、沙箱和存储，不宣称两端能力完全一致。

项目采用 MIT License；`LICENSE.txt` 是根目录 `LICENSE` 的静态站副本，修改许可时须同步。首页、指南与结构化数据已标明 MIT。公开仓库 URL 尚未确定，仍标注准备中，不生成虚假 GitHub 或下载链接。确认地址后需同步更新根 README、首页和指南。

## 内容维护

- `index.html`：产品介绍、运行方式、上手命令、FAQ 和 JSON-LD。
- `guide.html`：可随静态站独立发布的入门说明，与根 README 的环境、命令和能力边界保持一致。
- `app.js`：导航、截图切换、命令复制与 FAQ 动画。
- `styles.css`：现有响应式布局。
- `assets/`：现有产品截图与品牌素材。Office 说明限桌面内嵌预览、编辑和保存，不承诺云端多人协同。

## 验证与上线

本地检查桌面和移动布局、导航锚点、截图切换、命令复制成功与失败、FAQ 展开，以及首页和指南间跳转。修改 FAQ 时同步 JSON-LD；修改定位时同步 title、description 与社交分享元信息。

将 `website/` 作为公开静态根目录，确认首页、guide.html、图片、robots.txt、sitemap.xml 返回 200。规范域名为 https://picoddy.com/，服务器应将 HTTP 和 www 入口统一重定向到该域名。不要把源码配置、私有文件或服务凭据放入静态目录。

本地修改不等于线上发布；部署后再检查抓取与索引状态。结构化数据不保证搜索富媒体结果或 AI 引用。

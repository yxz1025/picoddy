# Web 本地测试配置收敛

背景：前端仍引用已删除的 Jenkins job、sharedEnvironment、buildNumber，与本地执行合同不一致。
目标：Web/H5/微应用以测试页面地址为唯一额外必填输入，名称默认仓库名，环境默认 test；删除 Jenkins 字段和报告关联。版本校验保留可选高级设置。
非目标：不启动测试、不修改启动或测试专家脚本，不自动部署或注册 MCP。
方案：表单与当前 TestTarget/TestRun 对齐；连接器允许留空，直接脚本执行由专家交付报告；已有配置的本地 MCP 跟踪仍保留，仅配置了本地连接器的记录显示读取结果。旧 Jenkins 配置编辑保存时清除。
影响：测试表单、目标保存校验、说明文档。
风险：直接脚本报告不会自动出现在登记运行列表，界面明确以专家报告为准；版本接口不填则不声称部署版本已校验。
验证：仅前后端 TypeScript 与差异检查，不运行测试或构建。

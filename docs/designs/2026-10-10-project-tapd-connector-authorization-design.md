# 项目 TAPD 授权统一到连接器中心

## 背景与现状

用户反馈项目中授权完成后，确认连接界面被遮挡，并建议统一跳转连接器授权。项目的原生 `dialog.showModal()` 位于浏览器 top layer；内部 `ConnectorCard` 的详情 portal 挂载到 body，无法覆盖原生弹窗，确认按钮被遮挡。

## 目标与方案

项目授权提示的按钮直接打开「专家·技能·连接器 → 连接器」的 TAPD 详情，移除项目授权弹窗。不自动发起浏览器授权，继续由用户点击连接或重新授权并确认。连接器页面提供“返回项目”，确认连接成功后自动返回，并立即触发项目授权检查与已有只读刷新。

临时导航状态记录本次授权来源。授权期间项目页面隐藏但保持挂载，保留当前需求、阶段、面板与输入。返回后恢复原页面；切往无关模块时清除临时导航状态。不重放写操作。

## 非目标与影响范围

不修改 OAuth、凭证、API、IPC 或其他连接器协议。修改前端导航、项目授权提示、TAPD 卡片及共用卡片的初始详情打开选项，清理旧项目弹窗样式。macOS 与 Windows 使用相同 React 逻辑，无平台依赖。

## 风险与验证

项目隐藏期间保留轮询与授权阻塞，确认后主动检查；关闭详情仍可通过返回按钮回项目。确认任意账号后项目继续独立检查当前工作空间覆盖，不将确认成功等同于工作空间已授权。检查前端 TypeScript 与差异格式，不自动运行测试套件。历史授权恢复文档标记新入口替代原地授权。

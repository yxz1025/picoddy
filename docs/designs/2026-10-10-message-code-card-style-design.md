# 消息代码与文本卡片样式调整

## 背景、目标与现状

用户提供 WorkBuddy 截图作为参考，要求改善当前输出卡片。现有 CodeBlock 使用整块灰底、较强边框与阴影、全大写语言名和复制文字按钮，视觉重量过高。代码、纯文本围栏共用此组件。

## 方案

统一改为浅灰标题栏、页面背景色正文、浅色细边框和圆角，无阴影。标题栏不再强调分隔线，语言名采用原始语言标记大小写，不强制大写。复制显示图标，使用 title、aria-label 与隐藏的状态文本保留操作提示和成功反馈。正文适当留白，保留等宽字体、高亮及长行横向滚动。行内代码去边框，使用浅灰底和普通深色文字。暗色模式使用现有主题变量。

## 非目标与影响范围

不改变消息内容、代码解析、复制逻辑和后端。修改 CodeBlock.tsx 与 ChatArea.css；纯文本和代码卡片同步生效，其他交付物卡片不纳入本次改动。前端样式在 Windows/macOS 共用。

## 风险与验证

避免隐藏复制按钮的可访问名称；长行不改变代码内容，流式和完整输出使用相同底色。执行前端 TypeScript 与差异检查，不运行测试套件。用户截图和参考作为明确视觉方案与实施授权。

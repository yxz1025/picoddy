# OpenAI ChatGPT 订阅认证

用户已确认的流程：设置中选择 OpenAI，使用 ChatGPT 浏览器授权；Pi 持久化和刷新令牌；会话页选择 OpenAI 模型后直接调用。保留 API Key 方式，不经过 MCP，不读取 ChatGPT 桌面客户端私有凭据。

## 实现与边界

- 使用 Pi 1.0.4 的 ModelRuntime.login/logout 和原生 OpenAI OAuth，包含 PKCE、本机回调与手动回调地址输入。安装标识持久保存，Windows/macOS 均使用同一 Node 原生实现。
- 令牌保存在应用数据目录 pi-agent/auth.json，与会话 ModelRuntime 共用。前端只接收授权状态与登录 URL；不接收访问令牌或刷新令牌。Pi 负责文件锁、持久化和刷新。
- 设置新增 ChatGPT 订阅与 API Key 两种入口。已有 API Key 用户默认保持原方式。浏览器自动打开受浏览器策略限制时可点击授权链接；取消及五分钟超时会结束授权。
- 已保存订阅凭据时，Pi 优先使用订阅。切换为 API Key 的按钮明确退出订阅；原钥匙串中的 Key 不删除。刷新失败不会偷偷改用 API Key。
- 默认模型校验、模型选择器、命令面板、模型目录和连接测试识别订阅授权。未配置 OpenAI 模型时展示 Pi 内置模型目录；已有模型选择不覆盖、不自动切换默认模型。
- 目录是 Pi 提供的模型目录，不是账号权益查询。模型实际可用性与额度由服务端判断。连接测试发起最小真实推理，可能消耗账号额度。
- HTTP、IPC、preload 与前端路由同步接入。MCP OAuth 仍是独立的连接器授权。

## 验证

- 专项组合 24/24：原生凭据持久化、重新加载、刷新、取消、退出；真实本机 OAuth 回调与 S256 PKCE；订阅无 Key 时模型可用性、保留用户选择、刷新失败不切换 Key；IPC 路由及原生会话恢复。
- OAuth 测试使用原生 Pi 登录实现和本地回调，令牌交换由测试响应替代，不接触生产账号。
- Playwright 隔离页面验证登录状态、手动回调、模型操作就绪、退出订阅切换 API Key；无页面脚本异常。
- TypeScript 检查和前端生产构建通过。

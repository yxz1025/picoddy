# 官网 SEO 与 GEO 优化

目标：使用用户确认的 https://picoddy.com 作为规范域名，提升公开产品内容的可抓取性和可理解性。

方案：优化标题和描述、明确主标题中的产品类别，添加可见产品定义及 FAQ，生成与正文一致的软件及价格结构化数据。提供 canonical、社交分享元信息、robots.txt 和单页 sitemap.xml。保留静态 HTML 内容，不堆砌关键词或隐藏提示。

边界：不修改环境配置，不部署线上、不代提交站长平台，不承诺排名和 AI 引用。仅对公开官网允许抓取，私有应用应部署独立认证环境。

验证：HTML 元信息与 JSON 解析、XML 解析、语法与差异检查；不运行测试套件。

# 每轮采用最新本地专家

背景：旧会话锁定创建时 revision，专家本地升级后旧缓存缺失导致初始化失败。用户确认每轮跟随本地最新版本。
目标：每轮准备时刷新本地个人专家和已安装市场专家目录，采用当前版本；校验与运行时 profile 构建成功后更新该会话绑定。
非目标：不拉取市场、不安装专家、不改历史消息和资产，不在正在执行的一轮中替换专家，不批量修改未使用会话。
方案：在 buildTurnEnvelope 的会话意图解析之前刷新本地目录并更新本轮行快照。原 resolveExpertProfile 校验最新 revision；成功后通过会话 binding store 写入最新版本。缺失或无效专家继续明确报错，不降级旧版。精确旧缓存解析保留给其他显式版本调用；已有缓存机制不作为本轮选版本依据。
影响：provider、专家系统文档。启动逻辑和执行队列不变，使用现有每轮 envelope 更新运行时。
风险与验证：只在有专家绑定时读取本地目录；绑定写入在校验之后。静态核查 session/profile 版本一致与技能资源同源，执行 TypeScript 和 diff 检查，不运行测试或触发真实消息。

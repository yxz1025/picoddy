# TAPD 未映射状态允许进入产研

## 背景与现状
ProjectPanel.importTapdRequirement 在状态映射缺失时返回，导致可正常读取的需求无法进入产研。

## 目标与方案
按用户本轮“先放开，直接进入”的明确指令实施。保留状态映射函数；移除入口映射缺失拦截。新需求无映射时默认设计分析（0）；已有需求保留 activeStage，无 activeStage 时由本地 stage 推导，与工作台当前显示规则一致。匹配状态继续使用现有映射。

## 非目标与影响范围
只调整前端进入产研的阶段选择，不修改 TAPD 状态写入、授权、需求读取权限、会话、产物提交或启动逻辑。

## 风险与验证
未知状态无法推断业务进度，因此不自动写回 TAPD。已有需求不能重置进度。执行前端 TypeScript 和差异检查，不运行测试或构建。本次无平台相关调用，macOS/Windows 使用相同前端逻辑。

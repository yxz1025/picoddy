# 需求聊天页输入资产栏横向滚动

## 背景与现状

用户下载并引用多个资产后，“本轮输入”区域使用 flex-wrap:wrap，随资产数量增加不断增高。该区域位于 ChatArea 和 Composer 之间，且不允许压缩，会挤占聊天区域。

## 目标与非目标

让资产栏稳定停留在底部输入框上方，资产数量不改变栏高；过多项目可左右滑动，聊天消息独立纵向滚动。保留需求、仓库和资产的点击查看、输入校验和原有发送行为，不增加资产管理或后端协议。

## 方案

将本轮输入布局分为固定标签、单行横向滚动的引用列表及独立提示行。引用按钮不缩小、不换行；长文件名限宽并省略显示，通过 title 提供完整名称。滚动列表使用 min-width:0、overflow-x:auto，支持触控板、触屏和水平滚动条，键盘聚焦按钮时可见。

资产栏和 Composer 保留在聊天布局的底部，不使用覆盖消息的绝对定位。ChatArea 分配剩余高度并设置 min-height:0，消息区域独立滚动。错误和仓库未关联提示放在列表外，避免被横向滚动隐藏；提示不随资产数量增加高度。

## 影响范围

RequirementChat JSX 与专属 CSS；更新专家系统文档。无数据迁移、依赖或平台特有 API。

## 风险与验证

关注侧栏打开和窄窗口时的横向溢出、长文件名、空资产、多个资产及校验提示。执行前端 TypeScript 和 git diff --check；按项目约束不自动运行测试套件或构建。布局基于标准 CSS，适用于 macOS 和 Windows。

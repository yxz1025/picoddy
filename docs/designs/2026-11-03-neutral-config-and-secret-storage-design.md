# 通用部署配置与凭据存储清理

用户已授权清理审查发现的全部项目内问题。

## 背景与目标
移除旧公司标识、企业地址、旧兼容文件与专属迁移脚本，停止安装包明文携带 SkillHub 密钥，避免 MCP 配置明文落盘。

## 方案
- CAS、SkillHub、对象存储等地址与凭据必须显式配置；测试使用保留示例域名。
- 删除 SkillHub 密钥打包及读取逻辑，仅保留环境变量和系统安全存储。
- MCP 配置整体通过 Electron safeStorage 加密后原子保存；Windows 使用系统保护，macOS 使用钥匙串，Linux 拒绝 basic_text 后端。无法加解密时明确报错，不退回明文。
- 拒绝旧明文 MCP 配置，用户重新配置；不引入迁移或兼容层。
- 本地环境文件清空凭据、公司地址和公司镜像；移除本地旧 SkillHub 加密凭据文件。

## 范围与非目标
更新源码、部署模板、测试源码和相关文档。不修改远端服务，不执行数据库迁移，不撤销或轮换远端凭据，不修改 Git 历史或已发布安装包。

## 风险
本地云端部署需重新填写配置后才能启动。旧 MCP 配置不再加载，需要重新配置。安装包不能再自动携带 SkillHub 共享密钥。

## 验证
执行 TypeScript 和语法检查、静态残留扫描及差异检查；维护加密落盘、明文拒绝和错误脱敏回归测试源码。按项目规则不自动运行测试或打包；Windows 实机启动验证需在 Windows 环境完成。

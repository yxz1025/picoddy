# 移除测试目标卡片的旧执行器入口

## 背景与目标
测试专家已经改为本地脚本执行，用户指出目标卡片中的检查本地环境、登记本地 MCP 不再需要。

## 方案与影响
移除目标卡片 validate/registerLocalMini 两个按钮，保留编辑及 CLI 自动检测。更新主说明、小程序准备说明和执行提示，指向测试专家本地脚本流程。只调整 UI 入口和文案，不改后端接口、历史记录、启动、会话及 TAPD 交付。

## 非目标与风险
本次不删除旧执行领域或迁移历史配置。环境前置条件仍由专家执行前检查，移除按钮不代表省略检查。配置编辑及历史记录结构保持不变。

## 验证
执行前端类型检查与差异检查，不运行测试或构建。平台无关的 React 变更适用于 macOS/Windows。

# 新建任务欢迎页移除分类快捷入口

## 背景与目标

用户通过截图明确要求直接删除标题和输入框之间的区域，包括主分类（日常办公、代码开发、设计创意）和子分类快捷入口。

## 现状

`ChatArea.tsx` 的 `WelcomeScreen` 渲染分类按钮，并通过事件选择技能、显示开发场景或打开微应用选择弹窗。`ChatArea.css` 提供对应布局与样式。

## 方案

欢迎页仅保留 PiCoddyClaw 标题和副标题。删除分类入口、专属状态与事件处理、未使用的场景数据及对应样式，使输入框通过现有欢迎页布局衔接标题。用户的直接删除指令作为本次明确范围的实施授权。

## 非目标与影响范围

不修改输入框的技能选择、工作空间、侧栏、后端协议或凭证存储。保留输入框依赖的共享技能模型，不扩展清理到其他模块。仅修改 React 与 CSS，不引入操作系统差异，Windows 使用相同界面。

## 风险与验证

清理导入时保留消息展示使用的图标；保留共享模块。执行前端 TypeScript 类型检查与 `git diff --check`，不运行自动测试套件。同步在历史技能选择文档中标记欢迎页入口已移除。

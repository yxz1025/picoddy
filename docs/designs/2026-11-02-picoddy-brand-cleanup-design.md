# PiCoddy 品牌清理

## 背景与目标
用户要求统一企业旧品牌为 PiCoddy，并明确所有 .env 不修改，以保持当前环境可启动。

## 范围与方案
统一源码、界面、文档和测试中的展示名、样例标识及文件引用。所有名称含 .env 的文件、凭据目录、真实服务地址和数据库连接保持原样。不执行数据库迁移，不改 Git 历史，不对二进制或 Base64 内容做字符串替换。

## 风险与非目标
旧域名拒绝规则与旧 manifest、数据库 provider 迁移中的历史值具有行为意义，保留原值，避免旧连接恢复或历史数据不可读。生成资源中的 Base64 偶然命中不属于品牌文字。不更换现有服务及存储桶。

## 验证
执行语法检查、差异检查及残留分类扫描，不运行测试套件。记录运行时兼容项及环境配置中的保留内容。

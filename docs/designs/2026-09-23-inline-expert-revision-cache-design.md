# 本地专家版本缓存

背景：测试专家包更新后，会话仍绑定旧 revision。旧版本解析要求精确校验缓存，但 inline 提示词此前未写缓存，导致初始化失败。
目标：本地 inline 提示词通过校验后写入既有版本缓存；更新包后允许旧会话恢复精确提示词。
非目标：不自动把旧会话切换到最新专家，不改变启动或消息/资产记录，不伪造旧 revision 缓存。
方案：复用 writeVerifiedCache 原子写入与 sha256 校验。当前已缺失的缓存无法重建，通过现有专家绑定接口将报错会话重新绑定至当前可用版本。
影响：prompt_resolver inline 分支。这里只缓存提示词，包内脚本资源不新增版本快照。
风险与验证：写入失败沿用初始化错误路径，避免产生未缓存的新绑定。执行类型与差异检查，不运行测试；绑定接口返回 ok 并核查数据库版本。

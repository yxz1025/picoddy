# 折叠侧边栏标题缩进与导航间距优化设计

## 背景

侧边栏折叠为 52px 窄轨后，聊天顶栏仍额外渲染一个“展开侧边栏”按钮，而侧边栏自身也保留了同功能按钮。重复入口把会话标题继续向右推开，导致折叠后标题没有随主内容向左收回。

折叠态目前只隐藏品牌、文字、徽标和列表，没有为标题栏、导航容器和导航按钮定义独立的尺寸与间距。图标仍继承展开态的 `padding`、`gap`、宽度和分组容器规则，折叠窄轨中的垂直节奏与水平居中缺少稳定约束。

## 目标

- 折叠后只保留一个展开入口，并放在侧边栏窄轨顶部居中。
- 移除聊天顶栏中的重复展开按钮，使会话标题随侧边栏折叠向左收回。
- 将“新建任务”和三个功能入口组织为紧凑、连续、等尺寸的图标栈。
- 所有折叠态导航图标保持水平居中、点击区域一致、垂直间距一致。
- 展开态布局和导航功能保持不变。

## 非目标

- 不改变侧边栏展开宽度、折叠宽度或折叠动画时长。
- 不调整会话列表、工作空间列表和底部用户头像的业务行为。
- 不修改功能入口的顺序、颜色、图标或路由。
- 不重做移动端导航。

## 现状与根因

`Sidebar.tsx` 在折叠态仍保留 `.sidebar-toggle-btn`，因为隐藏规则明确排除了该按钮；与此同时，`ChatArea.tsx` 在 `sidebarCollapsed` 为真时又渲染一个相同用途的按钮。聊天顶栏原有 `24px` 左内边距，再叠加 `28px` 按钮和 `8px` gap，使标题比正常内容起点多偏移约 36px。

`Sidebar.css` 的折叠态仅固定侧栏宽度并隐藏标签，没有覆盖：

- 标题栏左右 padding 与 `.sidebar-top-actions` 的自动外边距；
- `.sidebar-new-task` 与 `.sidebar-nav` 的折叠态 padding；
- `.sidebar-nav-item` 的固定宽高、居中方式、margin 和 gap；
- 图标在窄轨中的固定 flex 尺寸。

因此折叠后的图标位置仍依赖展开态规则，无法形成明确的紧凑图标轨道。

## 方案

### 1. 统一展开入口

- 删除 `ChatArea` 中基于 `sidebarCollapsed` 条件渲染的展开按钮。
- 同步删除 `ChatArea` 对 `sidebarCollapsed` 和 `toggleSidebar` 的无用订阅。
- 继续使用 `Sidebar` 自身的 `.sidebar-toggle-btn` 作为折叠态唯一展开入口。
- 折叠态将侧栏标题行与操作容器居中，并清除 `.sidebar-top-actions` 的 `margin-left: auto`，保证按钮位于 52px 窄轨中心。

这样聊天标题恢复使用 `.chat-header` 原有的 `24px` 内容缩进，不再额外被按钮推开。

### 2. 建立确定性的折叠导航节奏

仅在 `.sidebar.collapsed` 下覆盖布局：

- 标题栏水平 padding 调整为与 28px 展开按钮匹配的居中值；
- “新建任务”容器使用统一的 8px 水平 padding；
- 功能导航改为纵向 flex 栈，使用固定 `4px` gap；
- 每个导航按钮固定为 `36px × 36px`，清除展开态 margin、padding 和内部 gap；
- 导航按钮使用 `justify-content: center`，图标固定为 `18px` flex 项；
- “新建任务”按钮与功能导航使用相同按钮尺寸，二者之间保持 4px 级别的分组间距。

展开态继续使用现有文字导航布局，不共享这些覆盖规则。

## 影响范围

- `frontend/src/components/ChatArea.tsx`
- `frontend/src/components/Sidebar.css`
- 本设计文档及 `docs/README.md` 索引

## 风险与控制

- 展开入口丢失：只删除聊天顶栏的重复按钮，侧边栏内部按钮继续保留，并在折叠态显式居中。
- 展开态被折叠规则污染：所有新增规则都以 `.sidebar.collapsed` 为前缀。
- 点击区域过小：采用 36px 方形点击区，大于当前 28px 图标按钮，并保持图标本身 16～18px。
- 折叠动画抖动：不改变侧栏宽度动画，只调整宽度完成前后稳定的内部对齐属性。
- 标题离左侧过近：保留 `.chat-header` 原有 24px 左内边距，仅移除额外的 36px 按钮占位。

## 验证方式

- 前端 TypeScript 类型检查。
- `git diff --check`。
- 人工确认折叠态只有一个展开按钮，且位于窄轨顶部水平居中。
- 人工确认会话标题折叠后向左收回，并保持 24px 主内容缩进。
- 人工确认新建任务、专家与技能、自动化、工作台四个图标按 36px 点击区和 4px 间距连续排列。
- 人工确认展开态品牌、搜索、筛选、文字导航和会话列表布局不变。
- 按项目约束不自动运行测试套件。

# 微信开发者工具 CLI 自动检测

## 背景与现状
测试目标表单要求手填 CLI 绝对路径，跨平台使用不便。现有 testing-execution 可信 IPC 请求可复用。

## 目标与方案
根据用户要求在小程序 CLI 输入旁增加自动检测按钮。主进程领域服务仅检查本机文件：macOS 系统/用户 Applications 下常见应用名，Windows Program Files、Program Files (x86)、LocalAppData 下常见安装目录，以及 PATH。检测不执行发现的文件、不启动工具、不安装依赖。唯一结果回填，多个结果由用户选，零结果保留手动输入并说明可填写自定义安装位置。异步返回不得覆盖用户随后输入或切换的表单。

## 非目标与影响范围
不调整启动、会话、测试执行流程、TAPD 交付或授权。复用 testingExecutionSave 的 action，新增领域文件与前端按钮；IPC/preload 白名单和 HTTP 可信客户端限制保持现状。

## 风险与验证
自定义安装位置未必被常见目录覆盖，保留手动路径。路径存在不代表登录或服务端口就绪。Windows 无需 shell 命令，使用平台路径和环境变量；非支持系统返回明确提示。仅语法、TypeScript 和差异检查，不运行测试、构建或开发者工具。

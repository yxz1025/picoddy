# 测试产物提交与 TAPD 测试用例导入

## 背景与现状

用户要求测试阶段产物能像前序阶段一样提交到需求资产，并单独提供用例 Excel 上传按钮，目标是 TAPD 测试协同的测试用例。现有界面在测试阶段隐藏所有阶段提交操作，只有本地单文件提交；uploadTestingDelivery 只上传需求附件，未创建原生用例。现有 ExcelJS、模板校验、需求归属校验、TAPD 连接器凭证和附件接口可复用。

## 目标与非目标

生成任务交付后即可完成，不自动外部写入。两个独立操作：提交测试产物到需求资产/附件；将选定且已提交版本的 Excel 导入当前项目的测试协同用例并关联当前需求。保留覆盖矩阵和问题清单。不执行测试、不伪造执行次数、不推进 TAPD 状态、不将附件上传成功视为用例导入成功。

## 接口依据

TAPD 官方创建测试用例接口为 POST /tcases，一次创建一条，返回 Tcase ID，接受标题、目录 ID、前置条件、步骤、预期、等级及配置好的自定义字段。当前连接器也实现该接口和 stories/add_story_tcase。对接以原生测试协同 tcases 为目标，读取并校验 Excel 后逐条创建，不调用未经验证的网页 Excel 文件上传接口。

官方依据：https://open.tapd.cn/document/api-doc/API文档/api_reference/tcase/add_tcase.html

## 交互方案

1. 测试阶段新增“提交测试产物”按钮。收集当前会话明确交付的正式 Excel、覆盖矩阵和问题清单，登记为已提交资产并上传需求附件，返回每份产物的结果；不要求流转目标。输入 JSON、来源资产、源码不随操作上传。失败保留本地资产并可重试。
2. 新增独立“上传用例到 TAPD”按钮，选择当前会话已提交的 Excel 版本；只有一个候选时默认选中，多个候选明确选择文件。按钮旁显示文件、用例数和导入状态，点击即授权导入该版本，不增加额外审批节点。
3. 导入前回读不可变版本文件，核验资产 hash、模板和当前需求关联。显示进度及成功、已存在、失败和结果未知数量，并提供真实用例 ID/链接。失败后按记录续传，不重新生成文件。
4. 原有“帮我发布”的需求附件交付范围保持明确；新增“上传用例到测试协同”指令若接入，也必须复用同一导入领域服务与版本校验，不能使用模型自行传入的任意项目或文件路径。

## 字段与目录

读取项目实际用例字段配置，按当前模板列映射原生标题、前置条件、步骤、预期和等级。等级候选值、用例目录层级及自定义字段必须使用项目实际配置，不能臆造 P0 对应其它等级。目录按 Excel 路径查找或在当前项目创建。

标签、步骤描述类型、评估工时和执行次数等字段若原生 API 没有对应字段，先确认项目已有的字段配置；非空值不能静默丢失或随意塞入其他业务字段。遇到无法映射的非空字段，在导入前明确列出并阻断，Excel 原文件完整保留在资产中。关联需求由当前需求身份决定，拒绝 Excel 指向其它需求而未经授权的关联。

## 领域与安全边界

新增测试用例导入领域服务，复用 TAPD Bearer 凭证和 API base。身份由登录账户、需求空间、测试阶段会话及 testing-expert 的真实市场绑定确定。请求仅接受 assetId/hash，不接受任意 token、路径、账户或上传 URL。IPC、preload、前端路由映射及 HTTP 链路同步接入。

导入记录与账户、项目、需求、资产版本 hash 及行标识绑定，保存远端 ID、行内容 hash、创建/关联结果和错误。同一版本重复点击复用成功记录；创建成功但需求关联失败只重试关联。网络超时后结果未知时先查询核对，不能盲目创建第二条。新版本相同稳定 TC 编号与字段 hash 的行复用原记录；变化行保留版本差异信息，更新策略以确认范围为准，不能覆盖手工修改而无记录。

## 影响范围

RequirementChat 操作与状态展示、产物提交领域、Excel 读取/校验、TAPD 测试用例与目录/关联集成、导入记录、API/IPC 映射、测试专家运行时说明、回归测试源码与专家系统专项文档。

## 风险与验证

主要风险是字段/目录映射差异、部分成功重复导入、上传目标混淆及超时后重复创建。先预校验全部行和权限，逐条落回执并支持续传，区分附件状态与原生用例状态。按项目约束执行 TypeScript、语法和差异检查，不自动运行测试或构建。真实 TAPD 创建是外部写入，在实施完成后仅导入用户明确选择的版本，不擅自用虚构测试数据污染项目。

Windows 使用现有 Node、ExcelJS、platformPaths 和 IPC，不引入特定平台路径。未经实际验证不声称 Windows 构建/启动或真实用例导入通过。

# release 3.3.2：七牛一键构建并发布新版本

在仓库根目录执行，使用 Node 24。Windows 包在 Windows 上构建，Mac 包在 macOS 上构建。

3.3.2 的内置技能构建使用 Node 原生 `Buffer` 转换 SHA-256 十六进制摘要，兼容 Node 24，不依赖 `Uint8Array.toHex()`。

## 1. 首次准备

```sh
npm ci
npm --prefix frontend ci
```

将根目录 `.env.qiniu.example` 复制为 `.env.qiniu`，填写：

```dotenv
QINIU_ACCESS_KEY=你的AccessKey
QINIU_SECRET_KEY=你的SecretKey
QINIU_BUCKET=你的空间名称
```

`.env.qiniu` 已被 Git 忽略。也可以在 CI 环境变量中配置，凭据不会写入应用包或发布清单。空间区域默认由 SDK 查询，需要指定时加 `QINIU_REGION=z0` 等实际区域 ID。

## 2. 指定你的七牛域名，一条命令发布

```sh
npm run release:qiniu -- --version 3.3.2 --url https://cdn.example.com/picoddy/
```

**`--url` 由你指定**：填写已绑定到上述 Bucket 的 HTTPS CDN 下载域名和目录，必须以 `/` 结尾。不是七牛上传域名，也不是控制台地址。示例不能直接使用；可把 `/picoddyclaw/` 换成自己的目录，域名根目录也可以。

每次更换为更高的新版本号即可。命令自动完成：构建完整包 → 分片上传七牛 Kodo → 校验源站摘要、CDN 下载与 Range → 发布版本清单 → 提交 CDN 刷新。

默认当前操作系统和架构、`user` 安装范围、`stable` 通道、100% 发布；不是仅构建。版本注入最终应用包，发布成功后同步工作区 package.json 和 package-lock.json，不自动提交 Git。

网络上传不稳定时可只在本地构建并生成手动上传清单，不访问线上更新源，也不需要七牛发布密钥：

```sh
npm run release:qiniu -- --version 3.3.2 --url https://cdn.example.com/picoddy/ --manual-upload
```

构建目录中的 `manual-upload.md` 列出本地文件、目标 Key、下载 URL、大小和 SHA-512。先上传所有安装包与 blockmap，核对下载地址和摘要后，最后上传 `feed-staging/latest-mac.yml`、`feed-staging/latest.yml` 或对应 beta 清单，并保持 Key 不变。**必须使用 `feed-staging/` 下的清单**；构建输出根目录里同名的 electron-builder 原始清单缺少客户端校验所需的发布字段，上传它会报“更新包与当前平台或安装范围不匹配”。此模式不执行线上版本比较、发布锁、源站校验、CDN 刷新和本地版本号同步；需人工确认没有并发发布，并在上传后确认 CDN 内容可用。该计划没有自动发布所需的线上 ETag 基线，不能用于脚本重试或灰度操作。

如不想每次输入域名，可在 `.env.qiniu` 增加：

```dotenv
QINIU_UPDATE_URL=https://你的七牛下载域名/picoddy/
```

之后只需：

```sh
npm run release:qiniu -- --version 3.3.2
```

同时配置时，**命令行 `--url` 优先**。每个已分发客户端的更新地址已经写入包内，后续应保持该地址可用；仅修改新发布命令不会让旧客户端自动切换域名。

## 3. 七牛控制台配置

- 使用能直接下载的存储空间，并把指定的 HTTPS CDN 域名绑定到该 Bucket。当前客户端不支持私有下载 token 续期。
- 开启字节范围下载，返回 Range/206；不要对安装包动态压缩或改写内容。
- `feeds/` 清单缓存设为不超过 60 秒；`releases/` 安装包使用长缓存。CDN 规则不要覆盖脚本设置的缓存头。
- 发布凭据需有上传、查询资源、设置缓存元信息、删除发布锁和 CDN 文件刷新的权限。

上传使用七牛 SDK 和七牛上传服务，不向你的 CDN 域名发送 PUT，也不需要额外业务后端。CDN 刷新是异步的，命令成功表示刷新请求已提交，不表示所有边缘节点已经同步。

## 4. 可选参数

```sh
# Windows 32 位
npm run release:qiniu -- --version 3.3.2 --url https://你的七牛下载域名/picoddy/ --arch ia32

# Windows 全机器安装
npm run release:qiniu -- --version 3.3.2 --url https://你的七牛下载域名/picoddy/ --scope machine

# 先发布 5%，并附版本说明
npm run release:qiniu -- --version 3.3.2 --url https://你的七牛下载域名/picoddy/ --percentage 5 --notes release-notes.txt
```

Windows 和 Mac 各执行一次；同一个工作目录不要同时构建多个目标。制品保存在 `build/releases/<版本>-<目标>-<随机后缀>/`。

上传中断、灰度调整、撤回见[发布操作速查](remote-update-operations.md)。客户端仍由用户点击下载和安装；Mac 下载 DMG 后需手动覆盖应用，旧版没有更新能力时需先人工安装一次桥接包。

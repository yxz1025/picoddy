# PiCoddy 官网设计

用户已确认「轻盈工作台」方向。独立静态站放在 website/，不修改桌面与云端应用入口。

象牙白背景、炭黑标题、薄荷绿强调色，使用现有品牌图标。首屏展示品牌文案、开始使用入口、大幅交互工作台；下接四类工作场景、文件与工具能力、多模型与权限、三步启动、FAQ。桌面和移动端适配，键盘可操作，尊重减少动态效果偏好。

演示明确标注为交互示意，切换整理资料、分析表格、制作演示、开发页面时同步更新需求、步骤和交付预览。下载入口改为有依据的本地启动指引；不编造公开安装包、公开 GitHub 地址、客户数据或云端可用性。云端标注开发中，桌面与云端数据独立。源码入口指向当前 Git remote，不宣称该地址公开可访问。

交付：HTML/CSS/JS、品牌素材、运行说明、本地预览。暂不向托管服务上传仓库或部署。

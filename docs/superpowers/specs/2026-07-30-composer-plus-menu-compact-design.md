# Composer “+”菜单紧凑样式设计

## 目标

- 收紧聊天输入区“+”号一级菜单各选项的上下间距。
- 技能二级列表的图标由斜杠改为技能展示名称的首个有效字符。

## 范围

- 一级菜单项固定高度由 44px 调整为 36px。
- 二级菜单的模式、专家、连接器布局保持不变。
- 技能字符优先取 `displayName`，没有展示名称时取 `name`。
- 去除名称首尾空白后取第一个 Unicode 字符，兼容中文、英文和数字；没有有效字符时使用 `?`。
- 图标容器现有尺寸、颜色、圆角和交互状态保持不变。

## 组件与数据流

`ComposerPlusMenu` 在渲染技能列表时，根据 `SkillMeta` 计算图标字符并写入现有
`.composer-plus__skill-glyph` 容器。一级菜单继续使用
`.composer-plus__item`，仅调整其固定高度。

## 可访问性与交互

键盘导航、焦点样式、悬停展开、点击选择和菜单定位逻辑均不改变。字符图标作为技能
名称的视觉缩写，不新增可交互元素。

## 验证

- 单元测试覆盖中文展示名称、英文展示名称、缺少展示名称和空名称。
- 运行前端测试。
- 运行前端生产构建，确认 TypeScript 和 CSS 构建通过。

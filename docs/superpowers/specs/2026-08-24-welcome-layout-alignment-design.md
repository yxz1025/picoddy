# 新建任务欢迎区布局调整设计

## 目标

新建任务且尚无消息时，将右侧欢迎内容作为一个整体在可用区域内水平、垂直居中展示。适当增加输入框高度，并让二级菜单与输入框外框保持 5px 的垂直间距。

## 范围

- 仅调整普通聊天的新建任务欢迎态。
- 不改变已有消息的对话布局。
- 不改变自动化、专家和工作台页面。
- 不改变一级、二级菜单及输入框的现有交互行为。

## 布局设计

在 `App` 的普通聊天分支中，为欢迎态的 `ChatArea` 和 `Composer` 增加专用布局容器。该容器占满右侧可用空间，并将欢迎内容与输入框组成的内容组居中。

欢迎态内部从上到下保持现有信息顺序：

1. 品牌标题与副标题
2. 一级菜单
3. 二级菜单
4. 输入框

二级菜单底边到输入框外框顶边的可见距离固定为 5px。这个距离由欢迎态布局容器统一控制，不使用负边距。

## 尺寸与响应式行为

- 欢迎态输入编辑区最小高度调整为约 80px，最大高度继续沿用现有限制，避免输入过多时撑破页面。
- 输入框最大宽度继续沿用当前 860px，欢迎内容最大宽度继续沿用当前约束。
- 小窗口下保留现有左右安全边距；当内容高度超过可用空间时，允许页面自然收缩或滚动，不遮挡输入框。

## 实现边界

- 优先复用现有 `ChatArea`、`WelcomeScreen` 和 `Composer`，不搬迁菜单状态或输入状态。
- 新增的结构与样式仅通过欢迎态类名生效。
- 清理欢迎态现有依赖固定视口高度的定位规则，避免与新容器的居中逻辑冲突。

## 验证

- 新建任务时，右侧欢迎内容组在可用区域内视觉居中。
- 二级菜单与输入框外框间距为 5px。
- 输入框高度明显高于调整前，且工具栏仍完整可用。
- 切换一级、二级菜单以及输入内容不受影响。
- 发送首条消息后恢复现有对话布局。
- 前端 TypeScript 检查与构建通过。

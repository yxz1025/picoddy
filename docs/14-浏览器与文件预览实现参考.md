**关键设计决策：**

| 决策 | 方案 | 原因 |
|------|------|------|
| 浏览器容器 | `WebContentsView` | Electron 官方推荐，替代已废弃的 `<webview>` 标签和旧 `BrowserView` |
| CDP 端口 | `9224` | 独立于 Chrome MCP 的 9222，专供内置浏览器和 Agent 工具使用 |
| 视图定位 | React `ResizeObserver` → `setBounds()` | 原生视图需要像素级坐标，通过 DOM 测量动态同步 |
| 状态管理 | Zustand + IPC 推送 | 浏览器状态通过 `browser.state-changed` 事件从主进程推送到渲染进程 |
| 遮挡处理 | `browserOcclusionIds` Set | 通过唯一 ID 引用计数管理多个模态层遮挡 |
| 文件读取 | IPC `fs.readFile` | 文本/MIME 映射，图片转 data: URL |

## 2. 内置浏览器 —— 主进程 WebContentsView 管理

### 2.1 核心类：BrowserViewManager

```typescript

export class BrowserViewManager {
  private view: WebContentsView | null = null;
  private parentWindow: BrowserWindow | null = null;
  private visible = false;
  private viewDestroyed = false;
  private onStatusChange: ((status: BrowserStatus) => void) | null = null;

  private _blankPageBgColor = "#ffffff";
  private _isOnBlankPage = false;
```

### 2.2 生命周期

```typescript
// 创建 —— 使用安全的 webPreferences
create(parentWindow: BrowserWindow): void {
  this.view = new WebContentsView({
    webPreferences: {
      nodeIntegration: false,    // 禁用 Node.js
      contextIsolation: true,    // 开启上下文隔离
      sandbox: true,             // 开启沙箱
    },
  });

  const wc = this.view.webContents;

  // 监听导航事件，自动推送状态变更
  wc.on("did-start-loading", () => this._pushStatus());
  wc.on("did-stop-loading", () => this._pushStatus());
  wc.on("did-navigate", (_event, url) => {
    if (url !== this._blankPageUrl()) this._isOnBlankPage = false;
    this._pushStatus();
  });
  wc.on("did-navigate-in-page", () => this._pushStatus());
  wc.on("page-title-updated", () => this._pushStatus());
  wc.on("destroyed", () => { this.viewDestroyed = true; });

  // 初始加载空白页
  wc.loadURL(this._blankPageUrl());
  this._isOnBlankPage = true;
  this.view.setVisible(false);
}

// 销毁
destroy(): void {
  if (this.visible) this._removeFromWindow();
  this.view?.webContents.close();
  this.view = null;
  this.parentWindow = null;
  this.visible = false;
  this.viewDestroyed = true;
}

// 存活检查
isViewAlive(): boolean {
  return this.view !== null && !this.viewDestroyed;
}
```

### 2.3 可见性管理

关键设计：**视图先添加到窗口但不显示**，等 React 调用 `setBounds()` 后才真正可见。

```typescript
show(): void {
  if (!this.isViewAlive() || !this.parentWindow || this.visible) return;
  this.parentWindow.contentView.addChildView(this.view!);
  this.view!.setVisible(false);  // 关键：先隐藏，等 setBounds 后再显示
  this.visible = true;
  this._pushStatus();
}

hide(): void {
  if (!this.view || !this.parentWindow || !this.visible) return;
  this.view.setVisible(false);
  this._removeFromWindow();
  this.visible = false;
  this._pushStatus();
}

setBounds(x: number, y: number, width: number, height: number): void {
  if (!this.view || !this.visible) return;
  this.view.setBounds({ x, y, width, height });
  this.view.setVisible(true);  // 这里才真正显示
}
```

### 2.4 导航与状态

```typescript
navigate(url: string): void {
  if (!this.isViewAlive()) return;
  if (!this.visible) this.show();
  if (url === "about:blank") {
    this._isOnBlankPage = true;
    this.view!.webContents.loadURL(this._blankPageUrl());
  } else {
    this._isOnBlankPage = false;
    this.view!.webContents.loadURL(url);
  }
}

getStatus(): BrowserStatus {
  const wc = this.view?.webContents;
  const url = this._isOnBlankPage ? "about:blank" : (wc?.getURL() ?? "about:blank");
  return {
    visible: this.visible,
    url,
    title: wc?.getTitle() ?? "",
    isLoading: wc?.isLoading() ?? false,
    canGoBack: wc?.navigationHistory.canGoBack() ?? false,
    canGoForward: wc?.navigationHistory.canGoForward() ?? false,
  };
}
```

### 2.5 主题同步

通过 `data:text/html;base64` 渲染一个带主题色的空白页：

```typescript
setTheme(theme: "dark" | "light", blankPageBg?: string): void {
  if (blankPageBg !== undefined) this._blankPageBgColor = blankPageBg;
  if (this._blankPageTheme === theme && this.view && !this._isOnBlankPage) return;
  this._blankPageTheme = theme;
  if (this.view && this._isOnBlankPage) {
    this.view.webContents.loadURL(this._blankPageUrl());
  }
}

private _blankPageUrl(): string {
  // 颜色值做安全校验，只允许 hex/rgb
  const bg = /^#[0-9a-fA-F]{3,8}$|^rgb/.test(rawBg) ? rawBg : fallback;
  const html = `<!DOCTYPE html><html><head>
    <meta charset="utf-8">
    <meta name="color-scheme" content="${theme}">
    <style>html,body{margin:0;padding:0;height:100%;background:${bg};}</style>
    </head><body></body></html>`;
  return `data:text/html;base64,${Buffer.from(html).toString("base64")}`;
}
```

### 3.2 URL 标准化

```typescript
function normalizeUrl(input: string): string {
  const trimmed = input.trim();
  if (!trimmed) return "";
  if (/^https?:\/\//i.test(trimmed) || /^about:/i.test(trimmed)) return trimmed;
  // 有域名特征 → 自动补 https://
  if (/^[\w-]+(\.[\w-]+)+/.test(trimmed)) return `https://${trimmed}`;
  // 其他 → Google 搜索
  return `https://www.google.com/search?q=${encodeURIComponent(trimmed)}`;
}
```

### 3.3 视图坐标同步（核心逻辑）

WebContentsView 是原生视图，需要像素级坐标。使用 `ResizeObserver` 保持 React DOM 区域与原生视图的实时绑定：

```typescript
const syncBounds = useCallback(() => {
  if (!contentRef.current) return;
  const rect = contentRef.current.getBoundingClientRect();
  window.electronAPI?.browser.setBounds(
    Math.round(rect.x),
    Math.round(rect.y),
    Math.round(rect.width),
    Math.round(rect.height),
  );
}, []);

useEffect(() => {
  const el = contentRef.current;
  if (!el) return;
  syncBounds();
  const observer = new ResizeObserver(syncBounds);
  observer.observe(el);
  return () => observer.disconnect();
}, [syncBounds, width]);
```

## 4. 浏览器全屏与遮挡管理

### 4.1 Zustand Store 中的浏览器状态

**文件：** `src/renderer/store/index.ts`

```typescript
interface AppState {
  // 右侧面板模式：文件浏览器 / 内置浏览器 / 无
  rightPanelMode: "files" | "browser" | null;

  // 浏览器遮挡 —— 用于在渲染层模态框打开时隐藏原生浏览器视图
  browserOcclusionIds: ReadonlySet<string>;
  acquireBrowserOcclusion: (id: string) => void;
  releaseBrowserOcclusion: (id: string) => void;

  // 浏览器全屏
  isBrowserFullscreen: boolean;
  browserFullscreenSnapshot: {
    rightPanelMode: "files" | "browser" | null;
    contextPanelWidth: number;
  } | null;
  enterBrowserFullscreen: () => void;
  exitBrowserFullscreen: () => void;

  // 切换
  toggleBrowserPanel: () => void;
}

// 切换浏览器面板（打开时自动折叠侧边栏）
toggleBrowserPanel: () =>
  set((state) => {
    if (state.rightPanelMode === "browser") {
      return {
        rightPanelMode: null,
        sidebarCollapsed: state.sidebarCollapsedBeforeBrowser,
      };
    }
    return {
      rightPanelMode: "browser",
      sidebarCollapsedBeforeBrowser: state.sidebarCollapsed,
      sidebarCollapsed: true,
      browserWidthManual: false,
    };
  }),

// 全屏进入 —— 保存当前布局快照
enterBrowserFullscreen: () =>
  set((state) => ({
    browserFullscreenSnapshot: {
      rightPanelMode: state.rightPanelMode,
      contextPanelWidth: state.contextPanelWidth,
    },
    isBrowserFullscreen: true,
  })),

// 全屏退出 —— 恢复布局
exitBrowserFullscreen: () =>
  set((state) => {
    const snapshot = state.browserFullscreenSnapshot;
    return {
      isBrowserFullscreen: false,
      browserFullscreenSnapshot: null,
      ...(snapshot ? {
        rightPanelMode: snapshot.rightPanelMode,
        contextPanelWidth: snapshot.contextPanelWidth,
      } : {}),
    };
  }),
```

### 4.2 遮挡引用计数

使用 `Set<string>` 配合 React `useId()` 实现引用计数式遮挡：

```typescript
acquireBrowserOcclusion: (id) =>
  set((state) => {
    if (state.browserOcclusionIds.has(id)) return state;
    const ids = new Set(state.browserOcclusionIds);
    ids.add(id);
    return { browserOcclusionIds: ids };
  }),

releaseBrowserOcclusion: (id) =>
  set((state) => {
    if (!state.browserOcclusionIds.has(id)) return state;
    const ids = new Set(state.browserOcclusionIds);
    ids.delete(id);
    return { browserOcclusionIds: ids };
  }),
```

```typescript
export function useBrowserOcclusion(active: boolean): void {
  const id = useId();
  useLayoutEffect(() => {
    if (!active) return;
    useAppStore.getState().acquireBrowserOcclusion(id);
```

```typescript
function safeBrowserCall<T>(fn: () => T, fallback: T): T {
  try { return fn(); } catch (error) {
```

## 6. Agent 浏览器自动化工具 (CDP/Playwright)

**文件：** `src/main/agent/agent-runner.ts`

### 6.1 整体流程

```
Agent 调用 internal_browser_navigate(url)
  → _getOrCreateBrowserPage()
    → browserViewManager.show()    // 打开浏览器面板
    → chromium.connectOverCDP("http://127.0.0.1:9224")  // 连接 CDP
    → 过滤掉 app 窗口、devtools、extension 页面
    → 返回第一个内部浏览器 Page
  → page.goto(url)
```

### 6.2 获取/创建浏览器页面

```typescript
private async _getOrCreateBrowserPage(): Promise<Page> {
  this._browserViewManager?.show();

  if (this._browserPage && await this._isBrowserPageUsable(this._browserPage)) {
    return this._browserPage;
  }
  this._browserPage = null;

  const { chromium } = await import("playwright-core");

  if (!this._browser || !this._browser.isConnected()) {
    this._browser = await chromium.connectOverCDP(
      `http://127.0.0.1:${BROWSER_CDP_PORT}`,  // 9224
    );
    this._browser.on("disconnected", () => {
      this._browserPage = null;
      this._browser = null;
    });
  }

  // 过滤：排除 app 窗口、devtools、chrome-extension
  const appUrl = bvm?.getAppWindowUrl() ?? "";
  const pages = this._browser.contexts()[0]?.pages() ?? [];
  const internalPages = pages.filter((p) => {
    const u = p.url();
    if (appUrl && (u === appUrl || u.startsWith(appUrl + "/"))) return false;
    if (u.startsWith("devtools://")) return false;
    if (u.startsWith("chrome-extension://")) return false;
    return true;
  });

  this._browserPage = internalPages[0];
  return this._browserPage;
}
```

### 6.4 统一元素定位

支持三种定位方式：

1. **`@eN` 快照引用** —— 从 a11y snapshot 中解析 role/name/placeholder → `page.getByRole()`
2. **CSS 选择器** —— 直接传给 `page.locator(selector)`
3. **可见文本** —— 由 Playwright 的 `getByText` 等自动处理

```typescript
private _resolveLocator(page: Page, selector: string): Locator {
  const refMatch = /^@e(\d+)$/.exec(selector);
  if (refMatch && this._snapshotRefMap) {
    const info = this._snapshotRefMap.get(selector);
    if (info) {
      const { role, name, placeholder } = info;
      if (role === "textbox" || role === "searchbox") {
        if (placeholder) return page.getByPlaceholder(placeholder);
        if (name) return page.getByRole(role, { name });
      }
      if (role === "button") return page.getByRole("button", { name: name || "" });
      // ... 其他 role 处理
    }
  }
  return page.locator(selector);
}
```

### 8.2 代码预览（虚拟滚动 + 语法高亮）

使用 `react-window` 实现大文件的虚拟化渲染，结合 highlight.js 做按行语法高亮：

```typescript
const CodePreview = memo(function CodePreview({ content, ext }) {
  const lang = getLangFromExt(ext);
  const lines = useMemo(() => content.split("\n"), [content]);

  // 全文本高亮 → 按行拆分，保持跨行语法状态（如多行注释）
  const highlightedLines = useMemo(() => {
    const fullHtml = hljs.highlight(content, { language: lang }).value;
    const rawLines = fullHtml.split("\n");
    const openTagClasses: string[] = [];

    for (const raw of rawLines) {
      const opens = (raw.match(/<span class="([^"]*)">/g) || []);
      const closeCount = (raw.match(/<\/span>/g) || []).length;

      let line = openTagClasses.map(cls => `<span class="${cls}">`).join("");
      line += raw;
      // 追踪跨行的 span 标签
      for (const cls of opens) openTagClasses.push(cls);
      for (let i = 0; i < closeCount; i++) openTagClasses.pop();
      // 补齐未闭合标签
      for (const cls of openTagClasses) line += "</span>";
      result.push(sanitizeHighlight(line));
    }
  }, [content, lang]);

  return (
    <div ref={containerRef}>
      <List  // react-window 虚拟列表
        rowComponent={CodeRow}
        rowCount={lines.length}
        rowHeight={20}        // 每行 20px
        style={{ height }}
      />
    </div>
  );
});
```

**CodeRow** (虚拟行渲染器)：
```typescript
function CodeRow({ index, style, lines, highlightedLines }) {
  return (
    <div style={style} className="flex text-xs leading-5">
      <div className="w-10 text-right pr-3 text-text-muted">{index + 1}</div>
      <div className="flex-1 overflow-hidden whitespace-pre">
        {highlightedLines[index]
          ? <code dangerouslySetInnerHTML={{ __html: highlightedLines[index] }} />
          : <code>{lines[index]}</code>}
      </div>
    </div>
  );
}
```

安全措施：`sanitizeHighlight()` 只放行 `<span class="hljs-*">` 标签，其余全部转义。

### 12.4 移植要点

向 `picoddy` 项目移植时，需要关注：

1. **WebContentsView 而非 `<webview>`** —— 使用 Electron 的 `WebContentsView` API，它是官方推荐的嵌入浏览器方式
2. **CDP 端口独立** —— 为内置浏览器分配独立的 CDP 调试端口（9224），与外部 Chrome MCP 端口（9222）分离
3. **ResizeObserver 坐标同步** —— 原生视图的定位通过 React DOM 测量 + `ResizeObserver` 实时同步，而非 CSS 布局
4. **遮挡管理** —— 通过引用计数 Set 管理多个可能遮挡原生视图的渲染层模态框
5. **文件预览三层架构**：
   - 主进程：`fs.readFile` → MIME 识别 → 文本/Base64 图片
   - Preload：contextBridge 暴露类型安全 API
   - 渲染层：根据文件类型选择不同的预览渲染器
6. **安全性**：
   - `nodeIntegration: false`, `sandbox: true`, `contextIsolation: true`
   - 高亮 HTML 输出需要 sanitize
   - 空白页背景色需要校验（只允许 hex/rgb）
7. **目录懒加载** —— 文件树在首次展开目录时才请求子目录内容，避免启动时加载整个文件系统
